## 1. 各成员核心结论

### 🎨 设计师（视觉 / 配色 / 排版 / 栅格 / 交互）

- **核心判断**：AQP 定位应是 **「浅色为主、密度优先的专业研究终端」** —— 不学 Bloomberg 的「黑底霓虹」（A 股白天盯盘，高饱和荧光色更累），而学它的**信息密度、等宽数字对齐、键盘优先、F 键功能带**。一句话概括为「**纸质财经终端电子化**」：白/浅灰底、深墨字、克制的红绿、等宽数字。
- **配色解法（关键增量）**：红绿冲突的根因不是红绿本身，而是**把红绿拿去当了「危险/成功」**。解法 = **两套正交色系**：
  - **涨跌系** `up #D92B2B` / `down #12995B` —— 仅用于数字、K 线、涨跌箭头
  - **状态系** `danger #E11D48`（偏玫红）/ `success #0D9488`（偏青绿）/ `warn #D97706` / `info #2563EB` —— 仅用于按钮、徽章、提示条、熔断
  - 状态系**刻意选与涨跌系不同的色相/明度**，让用户一眼区分「这是价格」还是「这是状态」
- **对 `#DC2626`/`#16A34A` 的判断**：**方向保留、色值微调**（`#DC2626` 偏刺，久看累 → `#D92B2B` 更接近同花顺/东财的行情红；`#16A34A` 浅底偏亮 → `#12995B`）。
- **亮暗色推荐**：**亮色为默认**（A 股交易时段是白天，日光/办公照明下暗底 + 红绿发光溢出更累）；**`invert` hack 必须删除**，替换为 CSS 变量驱动的真暗色 token。
- **K 线图色值统一**：`KLineChart.tsx:18-23` 的 `#ee1515`/`#1dbf1d` 应改为**读 CSS 变量**，同时解决「图表红绿 ≠ 全站红绿」与「暗色下 `BG='#ffffff'` 穿帮」。
- **关键建议**：`OrderDesk` 的**主/操作区方向反了** —— 现状「账户+下单+Kill Switch 在左 4 / 母单子单表在右 8」，但下单才是主操作。应反转为「主表在左 8 / 操作区在右 4」，让 Kill Switch 永远固定可见。

### 🔍 产品官（任务流 / 信息架构 / 优先级）

- **核心判断**：18 个导航项是**按功能命名**而非**按任务命名**，导致每条任务路径都被切断。归纳出使用者实际只做 **5 类任务**（盘前预案 / 盘中盯盘 / 盘后研究 / 执行风控 / 数据运维），其中真正高频、横跨任务的只有约 **9 项**。
- **实锤的架构异味**：`Sidebar.tsx:160` 把 ETF **详情页**写成主导航项，需硬编码 `to='/etf/510300'` 并靠 `matchBase:'/etf/'` 与列表页**互斥高亮** —— 「这是在给错误建模打补丁」。
- **关键合并依据（我已独立验证）**：
  - **「策略研究」+「因子工作室」应合并** —— `Research/index.tsx` 头注释白纸黑字写着「**左上 因子研发中心**：features 截面 Rank IC / 相关矩阵 / 分层净值」，即 Research 内部**已包含**因子研发；FactorStudio 是 GP 自动挖掘。两者是因子生命周期的两段，被拆成两个平行入口。
  - **「组合回测」应并入「策略回测」** —— `Portfolio/index.tsx` 头注释确认它是「资产搜索/权重…策略类型」的**多资产模式回测**，加个模式切换即可。
  - **「容量与归因」应并入回测结果页** —— 340 行，内容是「容量上限评估 + Brinson 归因」，都是回测结果的下游分析。
- **关键建议**：导航 **18 项 → 9 项**（3 组 + 底部固定区 2 项）。理由：`w-40`（160px）侧栏已需 `overflow-y-auto` 滚动，18 项会让**关键入口滚出视野**；9 项可一屏零滚动，「眼睛扫一遍 1 秒内完成」是盯盘场景硬需求。剩余功能用「组内 Tab」承载 —— **深度增加但宽度收敛**。
- **拆的建议**：`StockDetail`（890 行）应把「公告/事件」抽成独立抽屉/路由 —— 它已有 `EVENT_PAGE_SIZE=15` + `EVENT_FETCH_STEP=15` + `EVENT_FETCH_MAX=200` + 独立滚动区，是**重度独立功能却被硬塞进 3×2 网格**。

## 🎨 附：可直接粘贴的颜色 token（designer 产出，P0-1 落地用）

```js
// frontend/tailwind.config.js → theme.extend.colors
colors: {
  canvas:  '#F1F4F8',
  surface: { DEFAULT: '#FFFFFF', alt: '#F8FAFC', sunken: '#EEF2F7' },
  ink: { DEFAULT:'#0F172A', secondary:'#475569', muted:'#94A3B8', inverse:'#FFFFFF' },
  hair: '#E2E8F0', hair2: '#CBD5E1',

  // 涨跌语义系（仅用于数字 / K线 / 箭头）
  up:   { DEFAULT:'#D92B2B', soft:'#FEE2E2', bg:'#FEF2F2', text:'#B91C1C' },
  down: { DEFAULT:'#12995B', soft:'#DCFCE7', bg:'#F0FDF4', text:'#047857' },
  flat: { DEFAULT:'#94A3B8', soft:'#F1F5F9', bg:'#F8FAFC', text:'#64748B' },

  // 状态语义系（仅用于按钮 / 徽章 / 提示条）—— 与涨跌系正交解耦
  danger:  { DEFAULT:'#E11D48', soft:'#FFE4E6', bg:'#FFF1F2', text:'#BE123C' },
  success: { DEFAULT:'#0D9488', soft:'#CCFBF1', bg:'#F0FDFA', text:'#0F766E' },
  warn:    { DEFAULT:'#D97706', soft:'#FEF3C7', bg:'#FFFBEB', text:'#B45309' },
  info:    { DEFAULT:'#2563EB', soft:'#DBEAFE', bg:'#EFF6FF', text:'#1D4ED8' },

  brand: { 50:'#EFF6FF',100:'#DBEAFE',200:'#BFDBFE',300:'#93C5FD',
           500:'#2563EB',600:'#1D4ED8',700:'#1E40AF' },
},
```

`text-emerald-600/700`(56) → 成功/正常走 `text-success`，表示跌走 `t-down`；`text-amber-*`(70) → `text-warn`。
