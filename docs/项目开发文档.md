## 1. 项目简介与目标

### 1.1 业务目标

AQP 是一个**面向 A 股的中小型量化投研一体化平台**，核心能力：

1. **数据层**：通过 AKShare 免费获取 A 股行情/财务/因子数据，落地 Parquet 列式仓库；
2. **因子工程**：提供 80+ 列基础特征集 `alpha_basic_v1`，支持增量构建；
3. **模型训练**：LightGBM 监督学习（Label = 未来 N 日收益率），含早停 / IC 筛选；
4. **回测引擎**：按交易日推进、T+1 撮合、涨跌停/停牌过滤、精确绩效评估；
5. **可视化前台**：React + Vite + Lightweight Charts 实现 K 线 / 市场概览 / 回测结果看板；
6. **生产可用**：统一异常、日志、缓存降级、Admin Token 鉴权、Docker Compose 一键部署。

### 1.2 非目标（OutOfScope）

- 不做实盘交易接入（仅预留接口）；
- 不做 Level-2 逐笔数据；
- 不做多因子正交化 / Barra 风险模型（可在 P2 阶段扩展）；
- 不做分布式训练（单机即可承载 5000 标的 × 10 年日频）。

### 5.4 核心配置 `backend/app/core/config.py`

```python
"""
全局配置加载。
- 优先读取环境变量；
- 其次读取项目根目录下的 .env 文件；
- 所有字段默认值保守、本地可跑（例如 SQLite 相对路径）。
"""
from functools import lru_cache
from pathlib import Path
from typing import Literal

from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict


# 项目根目录：从本文件上溯 4 层到仓库根目录 aqp/
# 层级关系（重构移动文件时务必同步修改此值）：
#   parents[0] = backend/app/core/      ← config.py 所在目录
#   parents[1] = backend/app/
#   parents[2] = backend/
#   parents[3] = aqp/                    ← 仓库根目录
#   parents[4] = Python_Project/        ← 仓库父目录（.git 所在层级的上一层）
# ⚠️ 若移动 config.py 到其他目录，必须重新计算 parents 索引。
PROJECT_ROOT: Path = Path(__file__).resolve().parents[3]  # aqp/


class Settings(BaseSettings):
    """应用配置，字段顺序 = 常用度排序。"""

    model_config = SettingsConfigDict(
        env_file=str(PROJECT_ROOT / ".env"),
        env_file_encoding="utf-8",
        extra="ignore",
    )

    # ---- 基础 ----
    ENV: Literal["dev", "test", "prod"] = Field(default="dev", description="运行环境")
    DEBUG: bool = Field(default=True, description="是否开启 debug 模式")
    APP_NAME: str = Field(default="AQP", description="应用名")
    ADMIN_TOKEN: str = Field(
        default="aqp-dev-token-change-me",
        description="后台管理接口的 Bearer Token；生产环境必须修改为强随机串",
    )

    # ---- 网络 ----
    API_HOST: str = Field(default="0.0.0.0")
    API_PORT: int = Field(default=8000)
    CORS_ORIGINS: list[str] = Field(
        default_factory=lambda: [
            "http://localhost:5173",
            "http://127.0.0.1:5173",
        ],
        description="允许跨域的前端地址",
    )

    # ---- SQLite ----
    SQLITE_URL: str = Field(
        default=f"sqlite+aiosqlite:///{PROJECT_ROOT / 'data' / 'sqlite' / 'aqp.db'}",
        description="SQLAlchemy 异步 URL，注意 3 斜杠 + 绝对路径",
    )

    # ---- Redis ----
    REDIS_HOST: str = Field(default="127.0.0.1")
    REDIS_PORT: int = Field(default=6379)
    REDIS_DB: int = Field(default=0)
    REDIS_PASSWORD: str | None = Field(default=None)
    REDIS_TIMEOUT: float = Field(default=1.0, description="Redis 超时秒；超时自动降级到内存")
    REDIS_ENABLED: bool = Field(default=True, description="Redis 总开关；False 时直接走内存缓存")

    # ---- Parquet 数据根 ----
    DATA_ROOT: Path = Field(default=PROJECT_ROOT / "data" / "parquet")
    MODEL_ROOT: Path = Field(default=PROJECT_ROOT / "data" / "models")

    # ---- 日志 ----
    LOG_LEVEL: str = Field(default="INFO")
    LOG_DIR: Path = Field(default=PROJECT_ROOT / "backend" / "logs")

    # ---- AKShare ----
    AKSHARE_RATE_LIMIT: float = Field(
        default=1.2,
        description="AKShare 两次请求之间的最小间隔秒数，东方财富会封临时 IP",
    )
    AKSHARE_RETRY: int = Field(default=3, description="重试次数")

    # ---- ML 超参（默认保守） ----
    ML_LABEL_HORIZON: int = Field(default=5, description="Label 为未来 N 日收益率")
    ML_HOLDOUT_DAYS: int = Field(default=252, description="测试集保留交易日（≈1 年）")


@lru_cache(maxsize=1)
def get_settings() -> Settings:
    """缓存配置对象，避免重复读文件。"""
    s = Settings()
    # 确保目录存在（首次运行）
    s.LOG_DIR.mkdir(parents=True, exist_ok=True)
    s.DATA_ROOT.mkdir(parents=True, exist_ok=True)
    s.MODEL_ROOT.mkdir(parents=True, exist_ok=True)
    return s
```

### 5.7 统一异常与响应 `backend/app/core/errors.py`

```python
"""
统一响应包装 + 全局异常处理器。
所有接口返回结构：
    { "code": 0, "message": "ok", "data": ..., "trace_id": "..." }
非 0 code 表示业务错误。
"""
from __future__ import annotations

import time
import uuid
from typing import Any, Generic, TypeVar

from fastapi import FastAPI, Request, status
from fastapi.encoders import jsonable_encoder
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from loguru import logger
from pydantic import BaseModel, Field

T = TypeVar("T")


class APIResponse(BaseModel, Generic[T]):
    code: int = Field(default=0, description="0 表示成功；非 0 业务错误码")
    message: str = Field(default="ok")
    data: T | None = Field(default=None)
    trace_id: str = Field(default_factory=lambda: uuid.uuid4().hex[:12])
    ts: int = Field(default_factory=lambda: int(time.time() * 1000))


def ok(data: Any = None, message: str = "ok") -> APIResponse[Any]:
    """成功返回。"""
    return APIResponse(code=0, message=message, data=data)


def fail(code: int, message: str, data: Any = None) -> APIResponse[Any]:
    """失败返回。注意 HTTP 200 + 业务 code。"""
    return APIResponse(code=code, message=message, data=data)


# ---------------- 业务错误码枚举（约定） ----------------
ERR_SYSTEM = 50000            # 未分类异常
ERR_PARAMS = 40000            # 请求参数错误
ERR_NOT_FOUND = 40400         # 资源不存在
ERR_UNAUTHORIZED = 40100
ERR_FORBIDDEN = 40300
ERR_DATA_SOURCE = 51000       # 外部数据源失败
ERR_DATA_EMPTY = 51001        # 本地无数据
ERR_TRAIN = 52000             # 训练失败
ERR_INFER = 52001             # 推理失败


class AQPException(Exception):
    """业务异常，message 会对外返回。"""

    def __init__(self, code: int, message: str, data: Any = None) -> None:
        self.code = code
        self.message = message
        self.data = data
        super().__init__(message)


def register_error_handlers(app: FastAPI) -> None:
    """把所有异常转为统一响应。"""

    @app.exception_handler(AQPException)
    async def _aqp(_: Request, e: AQPException) -> JSONResponse:
        logger.warning(f"AQPException code={e.code} msg={e.message}")
        return JSONResponse(
            status_code=200,
            content=jsonable_encoder(fail(e.code, e.message, e.data)),
        )

    @app.exception_handler(RequestValidationError)
    async def _validation(_: Request, e: RequestValidationError) -> JSONResponse:
        logger.warning(f"validation error: {e.errors()}")
        return JSONResponse(
            status_code=200,
            content=jsonable_encoder(fail(ERR_PARAMS, "请求参数错误", e.errors())),
        )

    @app.exception_handler(Exception)
    async def _exception(request: Request, e: Exception) -> JSONResponse:
        logger.opt(exception=True).error(f"unhandled error on {request.url.path}")
        return JSONResponse(
            status_code=200,
            content=jsonable_encoder(fail(ERR_SYSTEM, f"系统异常: {e.__class__.__name__}")),
        )
```

```python
"""SQLAlchemy 2.x async 会话工厂 + 依赖注入。"""
from __future__ import annotations

from collections.abc import AsyncGenerator

from sqlalchemy.ext.asyncio import (
    AsyncEngine,
    AsyncSession,
    async_sessionmaker,
    create_async_engine,
)
from sqlalchemy.orm import DeclarativeBase

from ..core.config import get_settings


class Base(DeclarativeBase):
    """所有 ORM 模型继承此类。"""


_engine: AsyncEngine | None = None
_async_session: async_sessionmaker[AsyncSession] | None = None


def _get_engine() -> AsyncEngine:
    global _engine
    if _engine is None:
        s = get_settings()
        # SQLite async 需要指定 aiosqlite 的 journal_mode / 连接参数
        # ⚠️ SQLite 并发写锁优化（WAL 模式）：
        #   WAL (Write-Ahead Logging) 允许读写并发，大幅减少 "database is locked" 错误。
        #   busy_timeout=30000ms 让写冲突时等待而非立即报错。
        #   PRAGMA journal_mode=WAL 在 init_db.py 中执行（持久化设置，DB 级别生效）。
        connect_args = {}
        if s.SQLITE_URL.startswith("sqlite+aiosqlite://"):
            connect_args = {
                "check_same_thread": False,
                "timeout": 30,           # busy_timeout: 30s
                # WAL 模式参数（每次连接时执行，确保 WAL 已开启）
                "journal_mode": "WAL",
                "synchronous": "NORMAL",  # WAL + NORMAL = 性能与安全平衡
            }
        _engine = create_async_engine(
            s.SQLITE_URL,
            echo=s.DEBUG,
            future=True,
            connect_args=connect_args,
            pool_pre_ping=True,
            # SQLite 连接池：单进程内复用，避免多连接争用
            pool_size=5,
            max_overflow=0,
        )
    return _engine


def get_session_factory() -> async_sessionmaker[AsyncSession]:
    global _async_session
    if _async_session is None:
        _async_session = async_sessionmaker(
            bind=_get_engine(),
            class_=AsyncSession,
            expire_on_commit=False,
            autoflush=False,
        )
    return _async_session


async def get_db() -> AsyncGenerator[AsyncSession, None]:
    """FastAPI 依赖：每次请求一个 session，自动回滚异常。"""
    factory = get_session_factory()
    async with factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
        finally:
            await session.close()
```

### 5.10 DB 初始化 `backend/app/db/init_db.py`

```python
"""
数据库初始化：
1. 创建 sqlite 文件所在目录；
2. Base.metadata.create_all；
3. （可选）写入基础字典数据。
"""
from __future__ import annotations

import asyncio
from pathlib import Path

from loguru import logger

from ..core.config import PROJECT_ROOT, get_settings
from .models import Base, TradeCalendar  # noqa: F401（确保 models 被注册）
from .session import _get_engine


async def init_database() -> None:
    """幂等执行：重复运行安全。"""
    s = get_settings()
    db_url: str = s.SQLITE_URL
    if db_url.startswith("sqlite+aiosqlite:///"):
        db_path = Path(db_url.replace("sqlite+aiosqlite:///", ""))
        db_path.parent.mkdir(parents=True, exist_ok=True)
        logger.info(f"sqlite db path: {db_path}")

    engine = _get_engine()
    async with engine.begin() as conn:
        from sqlalchemy import text

        # ⚠️ SQLite WAL 模式（Write-Ahead Logging）
        # 1. journal_mode=WAL：允许读写并发，大幅减少 "database is locked" 错误
        # 2. synchronous=NORMAL：WAL 模式下安全，性能优于 FULL
        # 3. busy_timeout=30000：写冲突时等待 30s 而非立即报错
        # 4. foreign_keys=ON：开启外键约束（SQLite 默认关闭）
        #    以上 PRAGMA 均为 DB 级持久化设置，首次执行后后续连接自动继承
        await conn.execute(text("PRAGMA journal_mode=WAL"))
        await conn.execute(text("PRAGMA synchronous=NORMAL"))
        await conn.execute(text("PRAGMA busy_timeout=30000"))
        await conn.execute(text("PRAGMA foreign_keys=ON"))
        await conn.run_sync(Base.metadata.create_all)
    logger.info("✅ database initialized (WAL mode + all tables created if not exist)")
    await engine.dispose()


if __name__ == "__main__":
    asyncio.run(init_database())
    print("db init done.")
```

### 5.11 Redis 客户端（带降级）`backend/app/cache/redis_client.py`

```python
"""
Redis 客户端封装，带三层防护：
1. 总开关 REDIS_ENABLED=False -> 直接降级内存缓存；
2. 超时 <= 1s -> 单次失败降级内存；
3. 连续失败 N 次 -> 熔断 1 分钟，期间全部走内存。
API 保持简单：get / set / delete / exists。
"""
from __future__ import annotations

import asyncio
import time
from typing import Any

from loguru import logger
from redis.asyncio import Redis, ConnectionPool

from ..core.config import get_settings
from .memory import lru_get, lru_set


_circuit_breaker = {
    "fail_count": 0,
    "open_until": 0.0,  # unixtime; < now 表示关闭
}
FAIL_THRESHOLD = 5
OPEN_SECONDS = 60


class RedisClient:
    _pool: ConnectionPool | None = None
    _client: Redis | None = None

    @classmethod
    def _ensure(cls) -> Redis | None:
        s = get_settings()
        if not s.REDIS_ENABLED:
            return None
        # 熔断
        if _circuit_breaker["open_until"] > time.time():
            return None
        if cls._client is None:
            cls._pool = ConnectionPool(
                host=s.REDIS_HOST,
                port=s.REDIS_PORT,
                db=s.REDIS_DB,
                password=s.REDIS_PASSWORD,
                socket_timeout=s.REDIS_TIMEOUT,
                socket_connect_timeout=s.REDIS_TIMEOUT,
                max_connections=32,
                retry_on_timeout=True,
            )
            cls._client = Redis(connection_pool=cls._pool)
        return cls._client

    @classmethod
    def _mark_fail(cls) -> None:
        _circuit_breaker["fail_count"] += 1
        if _circuit_breaker["fail_count"] >= FAIL_THRESHOLD:
            _circuit_breaker["open_until"] = time.time() + OPEN_SECONDS
            logger.warning(f"Redis circuit breaker OPEN for {OPEN_SECONDS}s")
            _circuit_breaker["fail_count"] = 0

    @classmethod
    def _mark_ok(cls) -> None:
        _circuit_breaker["fail_count"] = 0

    # ---------------- API ----------------
    @classmethod
    async def get(cls, key: str) -> bytes | None:
        r = cls._ensure()
        if r is None:
            v = lru_get(key)
            return v if isinstance(v, (bytes, type(None))) else None
        try:
            v = await asyncio.wait_for(r.get(key), timeout=get_settings().REDIS_TIMEOUT)
            cls._mark_ok()
            return v
        except Exception as e:
            cls._mark_fail()
            logger.trace(f"redis.get fallback {key}: {e!r}")
            v = lru_get(key)
            return v if isinstance(v, (bytes, type(None))) else None

    @classmethod
    async def set(cls, key: str, value: bytes, ex: int = 3600) -> None:
        # 永远双写内存，保证降级时可读
        lru_set(key, value)
        r = cls._ensure()
        if r is None:
            return
        try:
            await asyncio.wait_for(r.set(key, value, ex=ex), timeout=get_settings().REDIS_TIMEOUT)
            cls._mark_ok()
        except Exception as e:
            cls._mark_fail()
            logger.trace(f"redis.set fallback {key}: {e!r}")

    @classmethod
    async def delete(cls, key: str) -> None:
        from .memory import lru_del

        lru_del(key)
        r = cls._ensure()
        if r is None:
            return
        try:
            await asyncio.wait_for(r.delete(key), timeout=get_settings().REDIS_TIMEOUT)
        except Exception as e:
            cls._mark_fail()
            logger.trace(f"redis.delete fallback {key}: {e!r}")

    @classmethod
    async def ping(cls) -> bool:
        r = cls._ensure()
        if r is None:
            return False
        try:
            return bool(await asyncio.wait_for(r.ping(), timeout=0.5))
        except Exception:
            cls._mark_fail()
            return False
```

### 5.12 进程内 LRU `backend/app/cache/memory.py`

```python
"""
进程内 LRU：
- 主要作为 Redis 的降级；
- 也用于读频繁、写一次的极小对象（如交易日历数组）。
"""
from __future__ import annotations

from cachetools import LRUCache
import threading

# 容量 10w 条，足够覆盖 5k 股票 * 20 个热点 key
_CACHE: LRUCache = LRUCache(maxsize=100_000)
_LOCK = threading.RLock()


def lru_get(key: str):
    with _LOCK:
        return _CACHE.get(key)


def lru_set(key: str, value, ttl: int = 3600) -> None:
    """ttl 仅做近似：保存过期时间戳，读取时自行判断。

    这里实现极简版本：不主动清理。对于 AQP 而言 key 多为同一会话访问，可接受。
    """
    with _LOCK:
        import time

        _CACHE[key] = (time.time() + ttl, value)


def lru_del(key: str) -> None:
    with _LOCK:
        _CACHE.pop(key, None)


def lru_clear() -> None:
    with _LOCK:
        _CACHE.clear()


# ---- 覆盖：这里的 get 会自动判断过期，兼容上面 redis_client 直接取 bytes 的用法 ----
__orig_get = lru_get


def _lru_get_with_expire(key: str):
    v = __orig_get(key)
    if v is None:
        return None
    if isinstance(v, tuple) and len(v) == 2 and isinstance(v[0], (int, float)):
        import time

        if time.time() > v[0]:
            lru_del(key)
            return None
        return v[1]
    return v


# 替换导出（简单粗暴，但够用）
import sys as _sys

_sys.modules[__name__].lru_get = _lru_get_with_expire  # type: ignore[attr-defined]
```

### 5.18 交易日历工具 `backend/app/domain/calendar.py`

> **⚠️ 设计要点：避免异步上下文懒加载陷阱**
>
> 旧版 `ensure_loaded()` 尝试在同步函数里调用 `asyncio.run(_load())`，但 FastAPI 请求处理
> 始终运行在事件循环中，`asyncio.get_running_loop()` 会捕获到正在运行的 loop，导致 fallback
> 返回空集合 `_TRADE_DAYS = set()`，使 `is_trade_day()` 永远返回 False。
>
> **修正方案：**
> 1. 在 FastAPI `lifespan` 启动钩子中显式调用 `await load_trade_calendar_async()` 预加载；
> 2. `ensure_loaded()` 降级为同步 SQLAlchemy 查询（用 `sqlite3` 直连），不再碰 `asyncio`；
> 3. 脚本场景（无事件循环）调用 `load_from_db_sync()` 也能正常工作。

```python
"""交易日历判断：纯函数，无异步 IO。

数据由 bootstrap/update_daily 写入 SQLite 的 trade_calendar 表；
本模块提供日期判断与常用辅助。

加载策略（三选一，按优先级）：
1. lifespan 启动时调用 await load_trade_calendar_async() —— 推荐，FastAPI 场景
2. 脚本/测试场景调用 load_from_db_sync() 或 load_from_list()
3. ensure_loaded() 自动 fallback 同步查询（仅当 1/2 均未执行时）
"""
from __future__ import annotations

import sqlite3
from datetime import date, timedelta
from pathlib import Path

from loguru import logger

from ..core.config import get_settings

# 缓存：进程生命周期内不变，单次启动最多 load 1 次
_TRADE_DAYS: set[date] = set()
_LOADED = False


# ---------- 异步预加载（lifespan 调用）----------
async def load_trade_calendar_async() -> None:
    """在 FastAPI lifespan 启动钩子中调用，异步从 DB 加载交易日集合。

    使用场景：app/main.py 的 lifespan 函数中：
        await load_trade_calendar_async()
    """
    global _LOADED, _TRADE_DAYS
    try:
        from ..db.session import get_session_factory
        from ..db.models import TradeCalendar
        from sqlalchemy import select

        factory = get_session_factory()
        async with factory() as sess:
            res = await sess.scalars(select(TradeCalendar.trade_date))
            _TRADE_DAYS = set(res.all())
        _LOADED = True
        logger.info(f"交易日历异步加载完成: {len(_TRADE_DAYS)} 个交易日")
    except Exception as e:
        logger.warning(f"交易日历异步加载失败，将在首次使用时同步回退: {e}")
        _LOADED = False


# ---------- 同步加载（脚本/测试/fallback）----------
def load_from_db_sync() -> None:
    """同步从 SQLite 加载交易日历，适用于脚本或 ensure_loaded 的 fallback。

    使用 sqlite3 直连（不依赖 SQLAlchemy async session），在任何上下文均可安全调用。
    """
    global _LOADED, _TRADE_DAYS
    s = get_settings()
    db_path = s.SQLITE_PATH
    if not Path(db_path).exists():
        logger.warning(f"SQLite 文件不存在: {db_path}，交易日历加载跳过")
        _TRADE_DAYS = set()
        _LOADED = False
        return
    try:
        conn = sqlite3.connect(f"file:{db_path}?mode=ro", uri=True)
        rows = conn.execute("SELECT trade_date FROM trade_calendar WHERE is_open = 1").fetchall()
        conn.close()
        _TRADE_DAYS = {date.fromisoformat(r[0]) for r in rows}
        _LOADED = True
        logger.info(f"交易日历同步加载完成: {len(_TRADE_DAYS)} 个交易日")
    except Exception as e:
        logger.warning(f"交易日历同步加载失败: {e}")
        _TRADE_DAYS = set()
        _LOADED = False


def load_from_list(days: list[date]) -> None:
    """测试/脚本用：直接塞交易日集合，不走 DB。"""
    global _LOADED, _TRADE_DAYS
    _TRADE_DAYS = set(days)
    _LOADED = True


def ensure_loaded() -> None:
    """确保交易日历已加载。

    若 lifespan 已预加载（_LOADED=True），直接返回；
    否则用同步 sqlite3 查询作为 fallback（不碰 asyncio，避免事件循环冲突）。
    """
    global _LOADED, _TRADE_DAYS
    if _LOADED:
        return
    # 同步 fallback：用 sqlite3 直连，不依赖 async session
    load_from_db_sync()


def is_trade_day(d: date) -> bool:
    ensure_loaded()
    # 周末提前过滤
    if d.weekday() >= 5:
        return False
    return d in _TRADE_DAYS


def prev_trade_day(d: date) -> date:
    """往前找最近一个交易日，最多找 20 天。"""
    cur = d - timedelta(days=1)
    for _ in range(20):
        if is_trade_day(cur):
            return cur
        cur -= timedelta(days=1)
    raise ValueError(f"无法在 20 天内找到 d={d} 之前的交易日，请检查交易日历是否加载。")


def next_trade_day(d: date) -> date:
    cur = d + timedelta(days=1)
    for _ in range(20):
        if is_trade_day(cur):
            return cur
        cur += timedelta(days=1)
    raise ValueError(f"无法在 20 天内找到 d={d} 之后的交易日，请检查交易日历是否加载。")


def range_trade_days(start: date, end: date) -> list[date]:
    """闭区间 [start, end] 内的交易日列表，升序。"""
    ensure_loaded()
    out: list[date] = []
    cur = start
    while cur <= end:
        if is_trade_day(cur):
            out.append(cur)
        cur += timedelta(days=1)
    return out
```

### 5.19 复权算法 `backend/app/domain/adjust.py`

```python
"""
前复权 / 后复权 / 不复权。
规则（与通达信/东方财富通用约定一致）：
- 前复权 qfq：以最新价为基准，历史价向下调整（更常用，因为能和现价直接比较）；
- 后复权 hfq：以 IPO 首日为基准，所有价格都乘累计因子（用于长期收益率计算）；
- 不复权 none：直接返回原始价。

复权因子 adj_factor 约定：
    raw_close * adj_factor = 当日相对于基点的可比价（后复权价）。
因此：
    qfq = raw * factor / factor_today
    hfq = raw * factor
"""
from __future__ import annotations

from typing import Any

import polars as pl


def _to_pl(df: Any) -> pl.DataFrame:
    if isinstance(df, pl.DataFrame):
        return df
    if isinstance(df, (list, tuple)):
        return pl.DataFrame(df)
    import pandas as pd
    if isinstance(df, pd.DataFrame):
        return pl.from_pandas(df)
    raise TypeError(f"unsupported df type: {type(df)}")


def apply_adjust_df(
    df: Any,
    factor_df: Any,
    adjust: str = "qfq",
    price_cols: tuple[str, ...] = ("open", "high", "low", "close"),
) -> pl.DataFrame:
    """
    :param df:          OHLCV DataFrame，必须有 date/symbol + OHLC 列；
    :param factor_df:   复权因子表，列 date/symbol/adj_factor(后复权因子)；
    :param adjust:      qfq | hfq | none；
    :return:            返回带调整价的新 DataFrame（列名保持不变）。
    """
    if adjust not in {"qfq", "hfq", "none"}:
        raise ValueError(f"adjust must be qfq/hfq/none, got {adjust}")
    if adjust == "none":
        return _to_pl(df)

    bar = _to_pl(df)
    fac = _to_pl(factor_df).select(["symbol", "date", "adj_factor"])
    merged = bar.join(fac, on=["symbol", "date"], how="left")
    # 未匹配到因子（上市首日之前等）填 1
    merged = merged.with_columns(pl.col("adj_factor").fill_null(1.0))

    if adjust == "hfq":
        factor_col = pl.col("adj_factor")
    else:  # qfq
        # 每个 symbol 最新 factor（= 最后一个交易日）
        latest = merged.group_by("symbol").agg(pl.col("adj_factor").last().alias("f_today"))
        merged = merged.join(latest, on="symbol", how="left")
        factor_col = pl.col("adj_factor") / pl.col("f_today")

    exprs = [pl.col(c) * factor_col for c in price_cols]
    merged = merged.with_columns(exprs).drop(["adj_factor", "f_today"] if adjust == "qfq" else ["adj_factor"])
    return merged
```

```python
    list_date: date | None = None
    instrument_type: str = "stock"   # stock/etf/index


_TWO_DEC = Decimal("0.01")


def _twop(v: Decimal) -> Decimal:
    return v.quantize(_TWO_DEC, rounding=ROUND_HALF_UP)


def determine_board(attrs: InstrumentAttrs) -> str:
    """返回 main / chinext_star / bse / other。"""
    code = attrs.code
    # ETF / Index 默认 main
    if attrs.instrument_type != "stock":
        return "main"
    if re.fullmatch(r"(30\d{4}|688\d{4})", code):
        return "chinext_star"
    if re.fullmatch(r"[48]\d{5}", code):
        return "bse"
    return "main"


def is_new_issue_first_n_days(attrs: InstrumentAttrs, today: date, n: int) -> bool:
    if not attrs.list_date:
        return False
    if today < attrs.list_date:
        return False
    delta = (today - attrs.list_date).days
    return delta < n


def calc_limit_prices(
    prev_close: float | Decimal,
    attrs: InstrumentAttrs,
    today: date,
) -> tuple[Decimal, Decimal, Decimal]:
    """返回 (limit_up_price, limit_down_price, pct)。"""
    if prev_close is None:
        raise ValueError("prev_close 不能为 None（停牌/首日无昨收，需业务层判断）")
    pc = Decimal(str(prev_close))
    if pc <= 0:
        raise ValueError("prev_close 必须 > 0")

    board = determine_board(attrs)
    # 不设涨跌停的情况：直接返回 (inf, 0, None)，用很大/很小 Decimal 表示
    INF = Decimal("99999999.99")
    if board == "chinext_star" and is_new_issue_first_n_days(attrs, today, 5):
        return _twop(INF), Decimal("0.00"), Decimal("0")
    if board == "bse" and is_new_issue_first_n_days(attrs, today, 1):
        return _twop(INF), Decimal("0.00"), Decimal("0")

    if board == "main":
        pct = MARK_UP["main_st"] if attrs.is_st else MARK_UP["main"]
    elif board == "chinext_star":
        pct = MARK_UP["chinext_star"]
    elif board == "bse":
        pct = MARK_UP["bse"]
    else:
        pct = MARK_UP["main"]

    up = pc * (Decimal(1) + pct)
    dn = pc * (Decimal(1) - pct)
    return _twop(up), _twop(dn), pct
```

### 5.22 绩效指标 `backend/app/domain/metrics.py`

```python
"""
绩效评估：纯函数，输入净值序列（list[float] 或 np.ndarray），输出指标 dict。
公式说明：
- 年化收益：(last / first) ** (252 / N) - 1
- 夏普：      mean(daily_return - rf) / std(daily_return) * sqrt(252)，rf 默认 0
- 最大回撤：  max(1 - cur / peak)
- 胜率：      正收益日 / 全部交易日
- 盈亏比：    正收益平均 / |负收益平均|（任一为 0 返回 0）
- 年化换手：  sum(abs(delta_hold)) / sum(hold_avg) * 252 / N（turnover 若提供）
"""
from __future__ import annotations

from typing import Any

import numpy as np
import numpy.typing as npt


def _as_arr(x: Any) -> npt.NDArray[np.float64]:
    arr = np.asarray(list(x), dtype=np.float64)
    if arr.ndim != 1 or arr.size < 2:
        raise ValueError("净值序列长度必须 >= 2")
    if np.any(arr <= 0):
        raise ValueError("净值必须 > 0")
    return arr


def total_return(arr: Any) -> float:
    a = _as_arr(arr)
    return float(a[-1] / a[0] - 1.0)


def annual_return(arr: Any, trading_days_per_year: int = 252) -> float:
    a = _as_arr(arr)
    n = len(a) - 1
    if n <= 0:
        return 0.0
    return float((a[-1] / a[0]) ** (trading_days_per_year / n) - 1.0)


def annual_volatility(arr: Any, trading_days_per_year: int = 252) -> float:
    a = _as_arr(arr)
    r = np.diff(a) / a[:-1]
    if r.size < 2:
        return 0.0
    return float(np.std(r, ddof=1) * np.sqrt(trading_days_per_year))


def sharpe_ratio(arr: Any, rf: float = 0.0, trading_days_per_year: int = 252) -> float:
    a = _as_arr(arr)
    r = np.diff(a) / a[:-1]
    if r.size < 2:
        return 0.0
    excess = r - rf / trading_days_per_year
    std = np.std(excess, ddof=1)
    if std < 1e-12:
        return 0.0
    return float(np.mean(excess) / std * np.sqrt(trading_days_per_year))


def max_drawdown(arr: Any) -> tuple[float, int, int]:
    """返回 (mdd_ratio, peak_idx, trough_idx)。"""
    a = _as_arr(arr)
    peak = np.maximum.accumulate(a)
    dd = 1 - a / peak
    trough = int(np.argmax(dd))
    peak = int(np.argmax(a[: trough + 1]))
    return float(dd[trough]), peak, trough


def win_rate(arr: Any) -> float:
    a = _as_arr(arr)
    r = np.diff(a) / a[:-1]
    if r.size == 0:
        return 0.0
    wins = r > 0
    return float(np.mean(wins))


def profit_loss_ratio(arr: Any) -> float:
    a = _as_arr(arr)
    r = np.diff(a) / a[:-1]
    if r.size == 0:
        return 0.0
    pos, neg = r[r > 0], r[r < 0]
    if pos.size == 0 or neg.size == 0:
        return 0.0
    return float(np.mean(pos) / abs(np.mean(neg)))


def annual_turnover(turnovers_per_day: Any, trading_days_per_year: int = 252) -> float:
    arr = np.asarray(list(turnovers_per_day), dtype=np.float64)
    if arr.size == 0:
        return 0.0
    return float(np.mean(arr) * trading_days_per_year)


def all_metrics(nav: Any, turnovers_per_day: Any | None = None, rf: float = 0.0) -> dict[str, float | int]:
    a = _as_arr(nav)
    mdd, pk, tr = max_drawdown(a)
    return {
        "n_days": int(len(a) - 1),
        "total_return": total_return(a),
        "annual_return": annual_return(a),
        "annual_vol": annual_volatility(a),
        "sharpe": sharpe_ratio(a, rf=rf),
        "max_drawdown": mdd,
        "mdd_peak_day": int(pk),
        "mdd_trough_day": int(tr),
        "win_rate": win_rate(a),
        "profit_loss_ratio": profit_loss_ratio(a),
        "annual_turnover": annual_turnover(turnovers_per_day) if turnovers_per_day is not None else float("nan"),
    }
```

### 5.23 Parquet 仓库 `backend/app/data/parquet_store.py`

```python
"""
Parquet 分区读写。

> ⚠️ 分区粒度设计：
> 旧版按日生成 part-YYYYMMDD.snappy.parquet，5000 只 × 10 年 × 240 天/年 = 1200 万个
> 小文件，严重损害 IO 效率和文件系统性能。
>
> 修正方案：按 **年份** 分区，每只股票每年一个文件。
>   daily_bar/symbol=600519.SH/year=2024.snappy.parquet
> 5000 只 × 10 年 = 5 万个文件，每个文件 ~240 行 × 15 列，读写性能与增量更新均优异。
>
> 写入语义（原子替换）：
> 1. 先写到同目录的 .tmp 随机名；
> 2. fsync；
> 3. 原子 rename 覆盖旧文件。
> 4. 当日增量更新时：读取该年已有文件 → append 新行 → 原子重写整年文件。
"""
from __future__ import annotations

import os
import uuid
from datetime import date, datetime, timedelta
from pathlib import Path

import pandas as pd
import polars as pl
from loguru import logger

from ..core.config import get_settings


# ---------- 小工具 ----------
def today_trade_date_or_last() -> date:
    """占位：实际项目从 trade_calendar 取最近一个交易日；这里保守返回今天或昨天。"""
    today = date.today()
    if today.weekday() == 5:
        return today - timedelta(days=1)
    if today.weekday() == 6:
        return today - timedelta(days=2)
    return today


def _year_of(d: date | datetime | str) -> str:
    """提取年份字符串，用于按年分区路径。"""
    if isinstance(d, date):
        return str(d.year)
    if isinstance(d, datetime):
        return str(d.year)
    if isinstance(d, str):
        return d[:4]
    raise TypeError(f"bad date type: {type(d)}")


def _ensure_dir(p: Path) -> None:
    p.mkdir(parents=True, exist_ok=True)


# ---------- 路径约定 ----------
def path_for_year(dataset: str, symbol: str, year: int | str) -> Path:
    """按年分区路径：DATA_ROOT/dataset/symbol=XXX/year=YYYY.snappy.parquet"""
    s = get_settings()
    base = s.DATA_ROOT / dataset / f"symbol={symbol}"
    _ensure_dir(base)
    return base / f"year={year}.snappy.parquet"


def path_for(dataset: str, symbol: str, d: date | None = None) -> Path:
    """兼容旧接口：d 为 None 返回全量（all），否则返回该年分区。"""
    s = get_settings()
    base = s.DATA_ROOT / dataset / f"symbol={symbol}"
    _ensure_dir(base)
    if d is None:
        return base / "all.snappy.parquet"
    return path_for_year(dataset, symbol, _year_of(d))


# ---------- 读 ----------
def read_symbol_dataset(dataset: str, symbol: str,
                        start: date | None = None, end: date | None = None) -> pl.DataFrame:
    """读取某只股票的全部或区间数据（跨年份自动拼接）。"""
    s = get_settings()
    base = s.DATA_ROOT / dataset / f"symbol={symbol}"
    if not base.exists():
        return pl.DataFrame()
    # 扫描该 symbol 下所有 year=*.parquet
    scan = pl.scan_parquet(str(base / "year=*.snappy.parquet"))
    df = scan.collect()
    if df.is_empty():
        return df
    if "date" in df.columns:
        df = df.with_columns(pl.col("date").cast(pl.Date))
    if start and "date" in df.columns:
        df = df.filter(pl.col("date") >= start)
    if end and "date" in df.columns:
        df = df.filter(pl.col("date") <= end)
    return df.sort("date") if "date" in df.columns else df


def read_symbol_year(dataset: str, symbol: str, year: int | str) -> pl.DataFrame:
    """读取某只股票某一年的数据（单文件，最快路径）。"""
    target = path_for_year(dataset, symbol, year)
    if not target.exists():
        return pl.DataFrame()
    df = pl.read_parquet(target)
    if "date" in df.columns:
        df = df.with_columns(pl.col("date").cast(pl.Date))
    return df.sort("date") if "date" in df.columns else df


def read_all_symbols(dataset: str) -> list[str]:
    root = get_settings().DATA_ROOT / dataset
    if not root.exists():
        return []
    out = []
    for d in root.iterdir():
        if d.is_dir() and d.name.startswith("symbol="):
            out.append(d.name.split("=", 1)[1])
    return out


# ---------- 写（原子替换，按年分区） ----------
def write_partition(dataset: str, symbol: str, d: date, df: pl.DataFrame) -> Path:
    """写入某日的数据到对应年份分区。

    逻辑：读取该年已有文件 → concat 新数据 → 去重 → 原子重写。
    若该年文件不存在，直接创建。
    """
    if df.is_empty():
        raise ValueError("write_partition: df 为空")
    year = _year_of(d)
    target = path_for_year(dataset, symbol, year)
    # 读取已有数据
    if target.exists():
        existing = pl.read_parquet(target)
        df = pl.concat([existing, df], how="vertical_relaxed")
        # 按 date 去重，保留最后一条（增量更新场景）
        if "date" in df.columns:
            df = df.unique(subset=["date"], keep="last").sort("date")
    tmp = target.with_suffix(f".{uuid.uuid4().hex[:8]}.tmp")
    df.write_parquet(tmp, compression="snappy")
    _fsync_and_replace(tmp, target)
    logger.trace(f"parquet write ok: {target} rows={len(df)}")
    return target


def write_year_batch(dataset: str, symbol: str, year: int | str,
                     df: pl.DataFrame) -> Path:
    """整年批量写入（首次拉取或历史回补时使用，直接覆盖该年文件）。"""
    if df.is_empty():
        raise ValueError("write_year_batch: df 为空")
    target = path_for_year(dataset, symbol, year)
    tmp = target.with_suffix(f".{uuid.uuid4().hex[:8]}.tmp")
    df.write_parquet(tmp, compression="snappy")
    _fsync_and_replace(tmp, target)
    logger.trace(f"parquet year-batch write ok: {target} rows={len(df)}")
    return target


def write_whole_symbol(dataset: str, symbol: str, df: pl.DataFrame) -> Path:
    """适合 instruments / 小表（全量写一个文件）。"""
    if df.is_empty():
        raise ValueError("write_whole_symbol: df 为空")
    s = get_settings()
    base = s.DATA_ROOT / dataset / f"symbol={symbol}"
    _ensure_dir(base)
    target = base / "all.snappy.parquet"
    tmp = target.with_suffix(f".{uuid.uuid4().hex[:8]}.tmp")
    df.write_parquet(tmp, compression="snappy")
    _fsync_and_replace(tmp, target)
    return target


def _fsync_and_replace(tmp: Path, target: Path) -> None:
    """fsync + 原子 rename（Windows NTFS 也支持原子 replace）。"""
    fd = os.open(tmp, os.O_RDONLY)
    try:
        os.fsync(fd)
    finally:
        os.close(fd)
    os.replace(tmp, target)
```

### 5.24 AKShare 适配器 `backend/app/data/ingest/akshare_adapter.py`

```python
"""
AKShare 适配器：
1. 负责把 AKShare 返回的 DataFrame 统一成 AQP schema（列名/类型）；
2. 负责 rate limit + 重试（tenacity）；
3. 提供串行与并发两种拉取模式（全量更新时用并发缩短总耗时）。
"""
from __future__ import annotations

import random
import time
from concurrent.futures import ThreadPoolExecutor, as_completed
from datetime import date, datetime, timedelta
from typing import Any, Callable

import akshare as ak
import pandas as pd
import polars as pl
from loguru import logger
from tenacity import retry, stop_after_attempt, wait_exponential, retry_if_exception_type

from ...core.config import get_settings
from ...domain.a_share_rules import code_to_symbol


# ---------- 限速（线程安全版）----------
_last_call: float = 0.0
_call_lock = __import__("threading").Lock()


def _throttle() -> None:
    """限速：确保两次 AKShare 调用间隔不小于 AKSHARE_RATE_LIMIT（含抖动）。

    使用 threading.Lock 保证多线程并发场景下的限速安全。
    """
    global _last_call
    s = get_settings()
    jitter = random.uniform(0, s.AKSHARE_RATE_LIMIT * 0.3)
    gap = s.AKSHARE_RATE_LIMIT + jitter
    with _call_lock:
        need = _last_call + gap
        now = time.time()
        if now < need:
            time.sleep(need - now)
        _last_call = time.time()


@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=1, max=8),
    retry=retry_if_exception_type((Exception,)),
    reraise=True,
)
def _safe(func, *a, **k):
    _throttle()
    return func(*a, **k)


# ---------- 统一列名 ----------
_RENAME_DAILY = {
    "日期": "date", "开盘": "open", "收盘": "close", "最高": "high", "最低": "low",
    "成交量": "volume", "成交额": "amount", "振幅": "amplitude", "涨跌幅": "pct",
    "涨跌额": "change", "换手率": "turnover",
}


def fetch_trade_calendar(start: str = "20000101", end: str | None = None) -> pd.DataFrame:
    """返回 DataFrame[trade_date:date, is_sh/is_sz/is_bj]。"""
    end = end or date.today().strftime("%Y%m%d")
    df = _safe(ak.tool_trade_date_hist_sina)
    df["trade_date"] = pd.to_datetime(df["trade_date"]).dt.date
    df = df[(df["trade_date"] >= datetime.strptime(start, "%Y%m%d").date()) &
            (df["trade_date"] <= datetime.strptime(end, "%Y%m%d").date())].copy()
    df = df.assign(is_sh=True, is_sz=True, is_bj=True)
    df["week"] = pd.to_datetime(df["trade_date"]).dt.weekday + 1
    return df[["trade_date", "is_sh", "is_sz", "is_bj", "week"]].reset_index(drop=True)


def fetch_stock_list() -> pl.DataFrame:
    """拉 A 股 + 北交所列表，统一 schema。"""
    df = _safe(ak.stock_info_a_code_name)
    df = df.rename(columns={"code": "code", "name": "name"})
    df["symbol"] = df["code"].apply(code_to_symbol)
    df["market"] = df["symbol"].str.split(".").str[1]
    df["instrument_type"] = "stock"
    return pl.from_pandas(df)


def fetch_daily_bar(code: str, start: str, end: str, adjust: str = "") -> pl.DataFrame:
    """
    :param adjust: "" 不复权 / "qfq" / "hfq"
    返回 pl.DataFrame[date, open, high, low, close, volume, amount, ...]
    """
    func_map = {
        "":    ak.stock_zh_a_hist,
        "qfq": ak.stock_zh_a_hist,
        "hfq": ak.stock_zh_a_hist,
    }
    period = "daily"
    df = _safe(
        func_map[adjust],
        symbol=code,
        period=period,
        start_date=start.replace("-", ""),
        end_date=end.replace("-", ""),
        adjust=adjust,
    )
    if df is None or df.empty:
        return pl.DataFrame()
    df = df.rename(columns={k: v for k, v in _RENAME_DAILY.items() if k in df.columns})
    if "date" in df.columns:
        df["date"] = pd.to_datetime(df["date"]).dt.date
    df["code"] = code
    df["symbol"] = code_to_symbol(code)
    num_cols = ["open", "high", "low", "close", "volume", "amount"]
    for c in num_cols:
        if c in df.columns:
            df[c] = pd.to_numeric(df[c], errors="coerce")
    return pl.from_pandas(df)


# ---------- 并发批量拉取（全量更新用）----------
def fetch_daily_bar_batch(
    codes: list[str],
    start: str,
    end: str,
    adjust: str = "",
    max_workers: int = 4,
    progress_callback: Callable[[int, int, str | None], None] | None = None,
) -> dict[str, pl.DataFrame]:
    """并发拉取多只股票的日 K 数据。

    > ⚠️ 并发策略说明：
    > AKShare 限速较严，max_workers 不建议超过 4（每线程独立限速，
    > 总 QPS ≈ max_workers / AKSHARE_RATE_LIMIT）。
    > 全量 5000 只 × 0.4s/只 / 4 workers ≈ 8 分钟（不含网络延迟）。
    > 若 AKShare 封 IP，降低 max_workers=2 或改用单线程串行。

    :param codes: 股票代码列表，如 ["600519", "000001"]
    :param start: 起始日期 "YYYY-MM-DD"
    :param end: 结束日期
    :param adjust: 复权方式
    :param max_workers: 并发线程数，建议 2~4
    :param progress_callback: 进度回调 (done, total, error_code)
    :return: {code: DataFrame} 字典
    """
    results: dict[str, pl.DataFrame] = {}
    errors: list[str] = []
    total = len(codes)

    with ThreadPoolExecutor(max_workers=max_workers) as pool:
        future_map = {
            pool.submit(fetch_daily_bar, code, start, end, adjust): code
            for code in codes
        }
        done_count = 0
        for future in as_completed(future_map):
            code = future_map[future]
            done_count += 1
            try:
                df = future.result()
                if not df.is_empty():
                    results[code] = df
                else:
                    errors.append(code)
                    logger.warning(f"fetch_daily_bar_batch: {code} 返回空数据")
            except Exception as e:
                errors.append(code)
                logger.error(f"fetch_daily_bar_batch: {code} 失败: {e}")
            if progress_callback:
                progress_callback(done_count, total, code)

    logger.info(
        f"批量拉取完成: 成功 {len(results)}/{total}, 失败 {len(errors)}, "
        f"错误代码: {errors[:20]}{'...' if len(errors) > 20 else ''}"
    )
    return results


def fetch_daily_bar_batch_by_year(
    codes: list[str],
    year: int,
    adjust: str = "",
    max_workers: int = 4,
) -> dict[str, pl.DataFrame]:
    """按年份并发拉取，配合 parquet_store.write_year_batch 使用。

    :param year: 年份，如 2024
    :return: {code: DataFrame} 字典
    """
    start = f"{year}-01-01"
    end = f"{year}-12-31"
    return fetch_daily_bar_batch(codes, start, end, adjust, max_workers)
```

### 5.25 数据校验 `backend/app/data/ingest/validate.py`

```python
"""
数据校验函数集：每个函数返回 (ok: bool, errors: list[str])。
用途：盘后更新后做数据审计，有异常写入 data_update_log 并告警。
"""
from __future__ import annotations

from datetime import date
from typing import Any

import numpy as np
import polars as pl


def _ensure_pl(df: Any) -> pl.DataFrame:
    import pandas as pd
    if isinstance(df, pl.DataFrame):
        return df
    if isinstance(df, pd.DataFrame):
        return pl.from_pandas(df)
    raise TypeError(type(df))


def check_no_nulls(df: Any, cols: list[str]) -> tuple[bool, list[str]]:
    df = _ensure_pl(df)
    errs = []
    for c in cols:
        if c in df.columns and df[c].null_count() > 0:
            errs.append(f"列 {c} 含 {df[c].null_count()} 个空值")
    return (len(errs) == 0), errs


def check_range(df: Any, col: str, min_v: float | None, max_v: float | None) -> tuple[bool, list[str]]:
    df = _ensure_pl(df)
    if col not in df.columns:
        return False, [f"缺失列 {col}"]
    ser = df[col].cast(pl.Float64, strict=False).drop_nulls()
    if ser.is_empty():
        return False, [f"列 {col} 全为空"]
    bad = 0
    if min_v is not None:
        bad += int((ser < min_v).sum())
    if max_v is not None:
        bad += int((ser > max_v).sum())
    if bad:
        return False, [f"列 {col} 越界 {bad} 行（范围 [{min_v}, {max_v}]）"]
    return True, []


def check_ohlc_order(df: Any) -> tuple[bool, list[str]]:
    """high >= max(open,close)；low <= min(open,close)。"""
    df = _ensure_pl(df)
    need = {"open", "high", "low", "close"}
    if not need.issubset(df.columns):
        return False, [f"缺少 OHLC 列：{need - set(df.columns)}"]
    bad = df.filter(
        (pl.col("high") < pl.col("open")) |
        (pl.col("high") < pl.col("close")) |
        (pl.col("low")  > pl.col("open")) |
        (pl.col("low")  > pl.col("close"))
    ).height
    if bad:
        return False, [f"OHLC 顺序错误 {bad} 行"]
    return True, []


def check_volume_non_negative(df: Any) -> tuple[bool, list[str]]:
    return check_range(df, "volume", 0.0, None)


def check_pct_limit(df: Any, pct_col: str = "pct", max_abs: float = 0.33) -> tuple[bool, list[str]]:
    """涨跌停默认最大 ±30%（北交所），允许 ±33% 浮点误差。"""
    return check_range(df, pct_col, -max_abs, max_abs)


def check_no_duplicates(df: Any, keys: list[str]) -> tuple[bool, list[str]]:
    df = _ensure_pl(df)
    if not set(keys).issubset(df.columns):
        return False, [f"去重键缺失列：{set(keys)-set(df.columns)}"]
    dup = df.select(keys).is_duplicated().sum()
    if dup:
        return False, [f"键 {keys} 存在重复 {dup} 行"]
    return True, []


def check_row_count(df: Any, expect_rows: int, tol: float = 0.1) -> tuple[bool, list[str]]:
    n = _ensure_pl(df).height
    if abs(n - expect_rows) / max(expect_rows, 1) <= tol:
        return True, []
    return False, [f"行数 {n} 偏离预期 {expect_rows}（tol={tol}）"]


# ---------- 综合校验（Parquet 表维度） ----------
def validate_daily_bar(df: Any) -> tuple[bool, list[str]]:
    errs: list[str] = []
    for f in (
        lambda: check_no_nulls(df, ["date", "symbol", "open", "high", "low", "close", "volume"]),
        lambda: check_ohlc_order(df),
        lambda: check_volume_non_negative(df),
        lambda: check_pct_limit(df),
        lambda: check_no_duplicates(df, ["symbol", "date"]),
    ):
        ok, e = f()
        if not ok:
            errs.extend(e)
    return (len(errs) == 0), errs


def validate_instruments(df: Any) -> tuple[bool, list[str]]:
    errs = []
    ok, e = check_no_nulls(df, ["symbol", "code", "name", "market"])
    if not ok: errs.extend(e)
    ok, e = check_no_duplicates(df, ["symbol"])
    if not ok: errs.extend(e)
    return (len(errs) == 0), errs


def validate_predictions(df: Any) -> tuple[bool, list[str]]:
    errs = []
    ok, e = check_no_nulls(df, ["date", "symbol", "pred_score"])
    if not ok: errs.extend(e)
    ok, e = check_range(df, "pred_score", 0.0, 1.0)
    if not ok: errs.extend(e)
    return (len(errs) == 0), errs
```

### 5.26 特征集 `backend/app/ml/features.py`

```python
"""
alpha_basic_v1：约 80 列基础特征。
计算顺序（针对单个 symbol 日期序列）：
1) 基础 OHLCV → 价格动量 / 波动率；
2) 成交量相关；
3) 常用技术指标：MA/EMA/MACD/RSI/BOLL/ATR/OBV；
4) 高阶：偏度/峰度/最大回撤/过去 N 日 rank。

用 pandas-ta 加速，最终返回多索引 (symbol,date) DataFrame。
"""
from __future__ import annotations

from typing import Any

import numpy as np
import pandas as pd
import pandas_ta as ta
from loguru import logger


FEATURE_VERSION = "alpha_basic_v1"


def _one_symbol_feats(df: pd.DataFrame) -> pd.DataFrame:
    """df 含 date, open/high/low/close/volume/amount。"""
    df = df.sort_values("date").copy()
    c = df["close"]
    o = df["open"]
    h = df["high"]
    l = df["low"]
    v = df["volume"]

    out: dict[str, np.ndarray] = {}

    # ---- 价格动量（10 列） ----
    for w in [1, 3, 5, 10, 20]:
        out[f"ret_{w}"] = c.pct_change(w).values
    for w in [5, 10, 20, 60, 120, 250]:
        out[f"ma_gap_{w}"] = (c / c.rolling(w).mean() - 1).values

    # ---- 波动率（6 列） ----
    for w in [5, 10, 20, 60]:
        out[f"vol_{w}"] = c.pct_change().rolling(w).std().values
    out["hl_range"] = ((h - l) / c).values
    out["co_range"] = ((c - o) / c).values

    # ---- 量（10 列） ----
    for w in [5, 10, 20, 60]:
        out[f"v_ma_gap_{w}"] = (v / v.rolling(w).mean() - 1).values
    out["amount_per_share"] = (df.get("amount", v) / np.maximum(v, 1)).values
    out["v_std_5"]  = v.rolling(5).std().values
    out["v_std_10"] = v.rolling(10).std().values
    out["v_rank_20"] = v.rolling(20).rank(pct=True).values
    out["v_diff_1"] = v.diff().values

    # ---- 技术指标（20+ 列） ----
    for w in [5, 10, 20, 60, 120, 250]:
        ma = c.rolling(w).mean()
        out[f"ma_{w}"] = (c / ma - 1).values
    # EMA
    ema12 = c.ewm(span=12, adjust=False).mean()
    ema26 = c.ewm(span=26, adjust=False).mean()
    dif = ema12 - ema26
    dea = dif.ewm(span=9, adjust=False).mean()
    out["macd_dif"] = dif.values
    out["macd_dea"] = dea.values
    out["macd"] = (2 * (dif - dea)).values

    # RSI / KDJ 近似（用 pandas-ta 的存在性安全计算）
    try:
        rsi6  = ta.rsi(c, length=6);  out["rsi_6"]  = rsi6.values if rsi6 is not None else np.nan
        rsi14 = ta.rsi(c, length=14); out["rsi_14"] = rsi14.values if rsi14 is not None else np.nan
    except Exception:
        out["rsi_6"] = np.nan; out["rsi_14"] = np.nan

    # Bollinger 20
    m = c.rolling(20).mean()
    s = c.rolling(20).std(ddof=0)
    out["boll_up"]   = ((m + 2 * s - c) / c).values
    out["boll_down"] = ((c - (m - 2 * s)) / c).values
    out["boll_w"]    = (4 * s / m).values

    # ATR 14
    tr = pd.concat([h - l, (h - c.shift(1)).abs(), (l - c.shift(1)).abs()], axis=1).max(axis=1)
    out["atr_14"] = (tr.rolling(14).mean() / c).values

    # OBV 标准化
    sign = np.sign(c.diff().fillna(0))
    obv = (sign * v).cumsum()
    out["obv_norm"] = (obv / obv.rolling(250).max().replace(0, np.nan)).values

    # ---- 高阶统计（6 列） ----
    for w in [20, 60, 120]:
        out[f"skew_ret_{w}"] = c.pct_change().rolling(w).skew().values
        out[f"kurt_ret_{w}"] = c.pct_change().rolling(w).kurt().values

    # ---- 滚动 rank（未来信息：用全窗口 rank；12 列） ----
    for w in [20, 60, 120, 250]:
        out[f"rank_close_{w}"]  = c.rolling(w).rank(pct=True).values
        out[f"rank_volume_{w}"] = v.rolling(w).rank(pct=True).values
        out[f"rank_ret1_{w}"]   = c.pct_change().rolling(w).rank(pct=True).values

    # ---- 行业中性化占位：仅填 0（实际在训练前单独做 neutralize） ----
    out["industry_neutral_placeholder"] = np.zeros(len(df))

    # 组装
    res = pd.DataFrame(out, index=df.index)
    res["symbol"] = df["symbol"].iloc[0]
    res["date"]   = df["date"].values
    return res


def build_alpha_basic_v1(raw: pd.DataFrame) -> pd.DataFrame:
    """
    入参：raw 含 [symbol, date, open/high/low/close/volume/amount]；
    返回：(symbol, date, ... 80+ feature cols)。
    按 symbol 并行分组串行即可（数据量不大，<2 小时跑完）。
    """
    cols_need = {"symbol", "date", "open", "high", "low", "close", "volume"}
    if not cols_need.issubset(raw.columns):
        raise ValueError(f"raw 缺失列: {cols_need - set(raw.columns)}")
    chunks = []
    total = raw["symbol"].nunique()
    for i, (sym, g) in enumerate(raw.groupby("symbol", sort=False), 1):
        try:
            chunks.append(_one_symbol_feats(g.reset_index(drop=True)))
        except Exception as e:
            logger.warning(f"feature build fail symbol={sym}: {e!r}")
        if i % 500 == 0:
            logger.info(f"feature progress: {i}/{total}")
    if not chunks:
        return pd.DataFrame()
    out = pd.concat(chunks, ignore_index=True)
    # 清洗：inf -> nan
    out = out.replace([np.inf, -np.inf], np.nan)
    # 缺失值中位数填充（按 symbol 再填充为 0）
    feats = [c for c in out.columns if c not in {"symbol", "date"}]
    out[feats] = out.groupby("symbol")[feats].transform(lambda s: s.fillna(s.median()))
    out[feats] = out[feats].fillna(0.0)
    logger.info(f"features built: shape={out.shape}, n_cols={len(feats)}")
    return out
```

### 5.27 LightGBM 训练 `backend/app/ml/train_lgbm.py`

```python
"""
LightGBM 训练：
- Label = (close[t+n] / close[t]) - 1；二分类：将 top_k% 标 1，其他 0
- 时间序列切分：按日期升序，最后 N 个交易日做 valid / test
- 特征筛选：训练前计算 IC（Pearson/RankIC），仅保留 abs(RankIC) > 阈值
- 输出：model.lgbm + 训练日志 + model_registry 入库
"""
from __future__ import annotations

import json
from datetime import date, datetime
from pathlib import Path

import joblib
import lightgbm as lgb
import numpy as np
import pandas as pd
from loguru import logger
from scipy.stats import spearmanr, pearsonr
from sklearn.model_selection import train_test_split

from ..core.config import get_settings


DEFAULT_PARAMS = {
    "objective": "binary",
    "metric": "auc",
    "boosting_type": "gbdt",
    "learning_rate": 0.05,
    "num_leaves": 63,
    "feature_fraction": 0.8,
    "bagging_fraction": 0.8,
    "bagging_freq": 5,
    "min_data_in_leaf": 500,
    "lambda_l2": 0.1,
    "verbose": -1,
    "seed": 42,
    "n_jobs": -1,
    "force_row_wise": True,
}


def _calc_rank_ic(feat_s: pd.Series, label_s: pd.Series) -> float:
    mask = feat_s.notna() & label_s.notna()
    if mask.sum() < 100:
        return np.nan
    try:
        return float(spearmanr(feat_s[mask], label_s[mask]).correlation)
    except Exception:
        return np.nan


def select_features_by_ic(X: pd.DataFrame, y: pd.Series,
                          min_rank_ic: float = 0.01, top_k: int = 60) -> list[str]:
    ics: list[tuple[str, float]] = []
    for c in X.columns:
        ric = _calc_rank_ic(X[c], y)
        if not np.isnan(ric) and abs(ric) >= min_rank_ic:
            ics.append((c, abs(ric)))
    ics.sort(key=lambda x: x[1], reverse=True)
    keep = [c for c, _ in ics[:top_k]]
    logger.info(f"feature select: {len(keep)}/{len(X.columns)} kept (min_abs_rank_ic={min_rank_ic})")
    return keep or list(X.columns[:top_k])


def train_lgbm(
    features_path: Path | str,
    horizon: int = 5,
    holdout_days: int = 252,
    top_label_pct: float = 0.1,
    params: dict | None = None,
    version_suffix: str = "",
) -> dict:
    """
    :return: dict {model_path, version, valid_auc, valid_ic, valid_rank_ic, kept_features, ...}
    """
    s = get_settings()
    params = dict(params or DEFAULT_PARAMS)
    version = datetime.now().strftime("%Y%m%d_%H%M%S") + (f"_{version_suffix}" if version_suffix else "")
    model_dir: Path = s.MODEL_ROOT / f"lgbm_v1_{version}"
    model_dir.mkdir(parents=True, exist_ok=True)

    logger.info(f"load features from {features_path}")
    df = pd.read_parquet(features_path)
    df = df.sort_values(["symbol", "date"]).reset_index(drop=True)

    # Label 构造：未来 horizon 日收益率（注意标签泄露问题：必须按 symbol shift(-horizon)）
    df["label_ret"] = df.groupby("symbol")["close"].transform(
        lambda x: x.shift(-horizon) / x - 1.0
    )
    df = df.dropna(subset=["label_ret"]).copy()

    feat_cols = [c for c in df.columns if c not in {"symbol", "date", "label_ret", "close"}]
    X = df[feat_cols]; y_ret = df["label_ret"]

    # 按交易日切分
    dates = sorted(df["date"].unique())
    if len(dates) <= holdout_days + 20:
        raise ValueError(f"日期数不足({len(dates)})，无法留出 {holdout_days} 天测试")
    train_end = dates[-holdout_days - 1]
    train_mask = df["date"] <= train_end
    valid_mask = df["date"] >  train_end
    logger.info(f"train range: {dates[0]} ~ {train_end} n={train_mask.sum()}")
    logger.info(f"valid range: {dates[-holdout_days]} ~ {dates[-1]} n={valid_mask.sum()}")

    y_cls = (y_ret.rank(pct=True, ascending=False) <= top_label_pct).astype(int)

    X_tr, y_tr = X.loc[train_mask], y_cls.loc[train_mask]
    X_va, y_va_cls, y_va_ret = X.loc[valid_mask], y_cls.loc[valid_mask], y_ret.loc[valid_mask]

    # 特征选择（仅用训练集的 y_ret 统计 IC，防泄露）
    kept = select_features_by_ic(X_tr, y_ret[train_mask])
    X_tr_k = X_tr[kept]; X_va_k = X_va[kept]

    lgb_train = lgb.Dataset(X_tr_k, y_tr)
    lgb_valid = lgb.Dataset(X_va_k, y_va_cls, reference=lgb_train)

    callbacks = [
        lgb.early_stopping(stopping_rounds=50, verbose=True),
        lgb.log_evaluation(period=50),
    ]
    model = lgb.train(
        params, lgb_train,
        num_boost_round=1000,
        valid_sets=[lgb_valid],
        valid_names=["valid"],
        callbacks=callbacks,
    )

    model_path = model_dir / "model.lgbm"
    model.save_model(str(model_path))

    # 保存 feature list
    joblib.dump(kept, model_dir / "features.joblib")
    (model_dir / "params.json").write_text(json.dumps(params, ensure_ascii=False, indent=2))

    # 评估
    from sklearn.metrics import roc_auc_score
    pred_valid = model.predict(X_va_k, num_iteration=model.best_iteration or -1)
    try:
        auc = float(roc_auc_score(y_va_cls, pred_valid))
    except Exception:
        auc = float("nan")
    ic  = float(pearsonr(pred_valid, y_va_ret)[0]) if len(pred_valid) > 100 else float("nan")
    ric = float(spearmanr(pred_valid, y_va_ret).correlation) if len(pred_valid) > 100 else float("nan")

    logger.info(f"done: AUC={auc:.4f} IC={ic:.4f} RankIC={ric:.4f} -> {model_path}")
    return {
        "version": version,
        "model_path": str(model_path),
        "kept_features": kept,
        "valid_auc": auc,
        "valid_ic":  ic,
        "valid_rank_ic": ric,
        "num_rounds": int(model.best_iteration or -1),
    }
```

### 5.29 回测引擎 `backend/app/backtest/engine.py`

```python
"""
按交易日推进的向量化回测引擎（简化版）。

输入：
- universe_daily: pd.DataFrame[date, symbol, close, is_halted, limit_up, limit_down]
- signal_daily:   pd.DataFrame[date, symbol, pred_score]   （只关心 rank）
参数：
- init_cash=1e6, top_k=10, rebalance_freq="daily" / "weekly", commission=0.0003, stamp=0.0005
输出：
- 净值序列、持仓变化、交易记录、绩效汇总

撮合规则交给 broker.py，引擎只负责状态推进。
"""
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date
from typing import Any

import pandas as pd
import numpy as np
from loguru import logger

from ..domain.metrics import all_metrics
from .broker import Broker, Order, OrderSide


@dataclass
class BacktestResult:
    nav_df: pd.DataFrame                  # date, cash, equity, nav, turnover
    trades: list[dict] = field(default_factory=list)
    holdings_history: list[dict] = field(default_factory=list)
    metrics: dict[str, float | int] = field(default_factory=dict)


def run_backtest(
    universe: pd.DataFrame,
    signal:   pd.DataFrame,
    init_cash: float = 1_000_000,
    top_k: int = 10,
    rebalance_freq: str = "daily",   # daily / weekly (周五)
    commission_rate: float = 0.0003,
    stamp_duty: float = 0.0005,
) -> BacktestResult:
    uni = universe.sort_values(["date", "symbol"]).copy()
    sig = signal.sort_values(["date", "symbol"]).copy()
    dates = sorted(uni["date"].unique().tolist())
    logger.info(f"backtest: {len(dates)} days, top_k={top_k}, freq={rebalance_freq}")

    broker = Broker(init_cash=init_cash,
                    commission_rate=commission_rate,
                    stamp_duty=stamp_duty)
    rows = []
    trades_out: list[dict] = []
    holdings_out: list[dict] = []

    prev_d: date | None = None

    for idx, d in enumerate(dates):
        # 1) T 日开盘前：基于 T-1 收盘信号生成目标
        if rebalance_freq == "weekly":
            need_reb = (prev_d is None) or (d.weekday() == 4 and (prev_d is None or prev_d < d))
        else:
            need_reb = True

        target_syms: set[str] = set()
        if need_reb:
            # 用当日信号（若缺失则用上一日）
            sig_d = sig[sig["date"] == d]
            if sig_d.empty and prev_d is not None:
                sig_d = sig[sig["date"] == prev_d]
            if not sig_d.empty:
                target_syms = set(sig_d.nlargest(top_k, "pred_score")["symbol"].tolist())

        # 2) 取当日 universe
        uni_d = uni[uni["date"] == d].set_index("symbol")

        # 3) Broker 撮合：基于 T 日行情成交
        #    订单语义：SELL 全部非目标持仓；BUY 用剩余现金均摊目标
        orders: list[Order] = []
        # 先卖
        for sym in list(broker.holdings.keys()):
            if sym not in target_syms and broker.holdings[sym] > 0:
                orders.append(Order(symbol=sym, side=OrderSide.SELL,
                                    qty=broker.holdings[sym]))
        # 再买（等权）
        buyable = [s for s in target_syms if s in uni_d.index]
        if buyable:
            each_cash = broker.total_equity * 0.95 / len(buyable)
            for s in buyable:
                orders.append(Order(symbol=s, side=OrderSide.BUY, cash=each_cash))

        trades = broker.match(date_=d, orders=orders, universe_row=uni_d)
        trades_out.extend(trades)

        # 4) 更新持仓估值（T 日收盘）
        broker.mark_to_market(d, uni_d)

        rows.append({
            "date": d,
            "cash": float(broker.cash),
            "equity": float(broker.total_equity),
            "nav": float(broker.total_equity / init_cash),
            "turnover": float(broker.last_day_turnover),
        })
        holdings_out.append({
            "date": d,
            "holdings": dict(broker.holdings),
        })
        prev_d = d

    nav_df = pd.DataFrame(rows)
    if nav_df.empty:
        return BacktestResult(nav_df=nav_df)
    nav_arr = nav_df["nav"].values
    metrics = all_metrics(nav_arr, turnovers_per_day=nav_df["turnover"].values)
    logger.info(f"backtest done: {metrics}")
    return BacktestResult(nav_df=nav_df, trades=trades_out,
                          holdings_history=holdings_out, metrics=metrics)
```

### 5.30 撮合器 `backend/app/backtest/broker.py`

```python
"""
Broker：负责订单撮合，实现：
- T+1：今日买入的持仓今天不可卖（_locked_today）
- 涨跌停：买单封涨停不能买，卖单封跌停不能卖
- 停牌：成交量 0 或 is_halted=True 跳过
- 最低佣金 5 元 / 印花税卖出收取 0.05% / 过户费 A 股统一 0.001%（仅卖出，简化：忽略）
"""
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date
from enum import Enum
from typing import Any

import pandas as pd
import numpy as np
from loguru import logger


class OrderSide(str, Enum):
    BUY = "buy"
    SELL = "sell"


@dataclass
class Order:
    symbol: str
    side: OrderSide
    qty: int | None = None    # 若为 BUY 用 cash；若为 SELL 必须给 qty（股数）
    cash: float | None = None


@dataclass
class Trade:
    date: date
    symbol: str
    side: OrderSide
    price: float
    qty: int
    amount: float
    cost: float            # 手续费
    reason: str = ""


def _round_100(qty: float) -> int:
    """A 股一手 100 股，向下取整。"""
    return max(0, int(qty // 100) * 100)


class Broker:
    def __init__(self, init_cash: float, commission_rate: float = 0.0003, stamp_duty: float = 0.0005):
        self.init_cash = float(init_cash)
        self.cash = float(init_cash)
        self.commission_rate = commission_rate
        self.stamp_duty = stamp_duty
        self.holdings: dict[str, int] = {}           # 可卖持仓（股数）
        self._locked: dict[str, int] = {}            # 当日买入不可卖
        self._prev_close: dict[str, float] = {}
        self.total_equity: float = float(init_cash)
        self.last_day_turnover: float = 0.0

    def mark_to_market(self, date_: date, uni_d: pd.DataFrame) -> None:
        # 先把锁定 -> 可卖（T+1：下一交易日才能卖，这里推进到下一个 match 之前再释放更严谨，简化用“当天结束时即解冻第二天可卖”）
        for s, q in self._locked.items():
            self.holdings[s] = self.holdings.get(s, 0) + q
        self._locked.clear()

        mk = 0.0
        for s, q in self.holdings.items():
            px = float(uni_d.at[s, "close"]) if s in uni_d.index else self._prev_close.get(s, 0.0)
            mk += q * px
            if s in uni_d.index:
                self._prev_close[s] = px
        self.total_equity = self.cash + mk

    def _calc_cost(self, side: OrderSide, amount: float, instrument_type: str = "stock") -> float:
        comm = max(5.0, amount * self.commission_rate)
        stamp = amount * self.stamp_duty if (side == OrderSide.SELL and instrument_type == "stock") else 0.0
        return comm + stamp

    def match(self, date_: date, orders: list[Order], universe_row: pd.DataFrame) -> list[Trade]:
        trades: list[Trade] = []
        turnover = 0.0

        for o in orders:
            if o.symbol not in universe_row.index:
                continue
            row = universe_row.loc[o.symbol]
            halted = bool(row.get("is_halted", False))
            volume = float(row.get("volume", 0) or 0)
            close = float(row.get("close", 0) or 0)
            open_ = float(row.get("open",  close) or close)
            limit_up   = float(row.get("limit_up",   close * 1.2) or close * 1.2)
            limit_down = float(row.get("limit_down", close * 0.8) or close * 0.8)
            if halted or volume <= 0 or close <= 0:
                continue

            if o.side == OrderSide.SELL:
                qty_avail = self.holdings.get(o.symbol, 0)
                qty = min(int(o.qty or 0), qty_avail)
                if qty <= 0:
                    continue
                # 封跌停卖不出去：开盘价 == 最低价 == limit_down（简化）
                if open_ <= limit_down * 1.0001:
                    continue
                # 成交均价：简化用 open（更保守）
                price = open_
                amount = price * qty
                cost = self._calc_cost(OrderSide.SELL, amount)
                self.cash += amount - cost
                self.holdings[o.symbol] = qty_avail - qty
                if self.holdings[o.symbol] == 0:
                    self.holdings.pop(o.symbol, None)
                turnover += amount
                trades.append(Trade(date_, o.symbol, OrderSide.SELL, price, qty, amount, cost))

        for o in orders:
            if o.side != OrderSide.BUY or o.cash is None:
                continue
            if o.symbol not in universe_row.index:
                continue
            row = universe_row.loc[o.symbol]
            halted = bool(row.get("is_halted", False))
            volume = float(row.get("volume", 0) or 0)
            close = float(row.get("close", 0) or 0)
            open_ = float(row.get("open",  close) or close)
            limit_up = float(row.get("limit_up", close * 1.2) or close * 1.2)
            if halted or volume <= 0 or close <= 0:
                continue
            if open_ >= limit_up * 0.9999:
                continue
            price = open_
            use_cash = min(float(o.cash), self.cash * 0.99)
            if use_cash <= 100:
                continue
            pre_cost_max = use_cash * (1 + self.commission_rate) + 5
            qty = _round_100(use_cash / price)
            if qty <= 0:
                continue
            amount = price * qty
            cost = self._calc_cost(OrderSide.BUY, amount)
            if amount + cost > self.cash:
                # 再减一手
                qty -= 100
                if qty <= 0:
                    continue
                amount = price * qty
                cost = self._calc_cost(OrderSide.BUY, amount)
                if amount + cost > self.cash:
                    continue
            self.cash -= (amount + cost)
            self._locked[o.symbol] = self._locked.get(o.symbol, 0) + qty
            turnover += amount
            trades.append(Trade(date_, o.symbol, OrderSide.BUY, price, qty, amount, cost))

        self.last_day_turnover = turnover / max(self.total_equity, 1.0)
        return [t.__dict__ for t in trades]
```

```python
        assert rh["close"].to_list() == pytest.approx([15.0, 18.15], rel=1e-6)

        expect_last = 18.15 / (1.5 * 1.1)  # = 11.0
        assert rq["close"].to_list()[-1] == pytest.approx(expect_last, rel=1e-6)
```

### 6.2 Parquet 仓库总览（列式的原因）

| 维度 | 说明 |
|---|---|
| 为什么选 Parquet | 1) 列式压缩：A 股全历史 OHLCV 可从 50GB CSV 压到 2~3GB；2) 列裁剪（只需 close/volume）IO 极小；3) 类型安全 + 分区友好 |
| 压缩算法 | snappy（速度/压缩比平衡，OLAP 场景首选） |
| 分区粒度 | `symbol=xxx/year=YYYY.snappy.parquet`（按 symbol 大分区、year 小分区，5000×10年=5万文件，避免数百万小文件） |
| 原子写入 | `tmp` → `fsync` → `os.replace`，避免半写文件 |
| 备份策略 | 每周 `tar czf parquet-backup-YYYYMMDD.tar.gz data/parquet`，增量可用 `rsync` |

### 6.3 Parquet 数据集清单

| 数据集 | 路径 | 列（核心） | 分区 | 校验入口 |
|---|---|---|---|---|
| daily_bar | `parquet/daily_bar/symbol=X/part-DATE` | date, open, high, low, close, volume, amount, pct, turnover | symbol, date | `validate_daily_bar` |
| adj_factor | `parquet/adj_factor/symbol=X/part-DATE` | date, adj_factor (后复权累计因子) | symbol, date | `check_no_nulls` + `check_range(factor, 0.1, 100)` |
| financial | `parquet/financial/symbol=X/part-YYYYQ{N}` | report_date, revenue, net_profit, roe, eps, pe_ttm... | symbol, 季度 | `check_no_nulls` |
| features | `parquet/features/version=alpha_basic_v1/date=DATE` | date, symbol, 80+ 特征列 | date, version | `check_no_nulls(所有特征)` + `check_row_count` ≈ 股票总数 |
| predictions | `parquet/predictions/date=DATE` | date, symbol, pred_score ∈ [0,1] | date | `validate_predictions` |
| instruments | `parquet/instruments/symbol=__all__/all.snappy.parquet` | code, symbol, name, market, list_date, industry | (单文件) | `validate_instruments` |
| trade_calendar | `parquet/trade_calendar/all.snappy.parquet` | trade_date, is_sh, is_sz, is_bj, week | (单文件) | `check_no_nulls` + 行数预期 ≈ 年 250 天 |

### 6.4 完整的数据校验规则（逐项）

| 数据集 | 校验项 | 阈值 | 失败动作 |
|---|---|---|---|
| daily_bar | 空值检查 date/symbol/open/high/low/close/volume | 0 容忍 | 写 failed 日志，跳过该 symbol 当日 |
| daily_bar | OHLC 顺序 | high≥max(O,C), low≤min(O,C) | 同上 |
| daily_bar | volume ≥ 0 | 0 | 同上 |
| daily_bar | pct 绝对值 ≤ 33%（含新股 44%+1 日熔断场景） | ±0.33 | 告警，人工复核 |
| daily_bar | symbol+date 重复 | 0 容忍 | 去重后覆盖写 |
| daily_bar | 行数 ≈ 标的总数 × 1日 | 10% 容差 | 标记 partial，下次重跑 |
| adj_factor | adj_factor ∈ [0.1, 100] | — | 异常符号剔除 |
| adj_factor | 日期连续 | 连续交易日无跳天 ≤ 2 | 缺失日 forward fill |
| features | 每列 NaN 比例 | ≤ 5% | 否则回滚重算 build_features |
| features | 行数 × 日期 | 偏离历史平均 ≤ 10% | 告警 |
| predictions | pred_score ∈ [0,1] | — | 裁剪 clamp(0,1) 并告警 |
| predictions | rank 单调性 vs 昨日 | Spearman ≥ 0.7 | 否则怀疑推理异常 |
| instruments | symbol/code/name/market 非空 | 0 | 拒绝入库 |
| trade_calendar | 工作日集合一致性 | 非周末交易日占比 ≥ 96% | 人工检查休市日历 |

## 7. 缓存设计（Redis Key 表 + 读取顺序 + 降级）

### 7.1 缓存读取/写入顺序

```
读：请求 -> RedisClient.get -> (命中 OR 熔断/超时) -> LRU -> Parquet/SQLite -> 双写 Redis+LRU
写：业务函数 -> LRU.set + Redis.set（并行）；Redis 失败不抛错
删：LRU.del + Redis.del
```

### 7.2 Key 一览表

| Key 模板（生成函数） | 类型 | TTL | 数据大小 | 说明 |
|---|---|---|---|---|
| `aqp:health:1` | string | 10s | 小 | 健康检查缓存（实际没做，预留） |
| `aqp:market:indices:YYYYMMDD` | bytes(JSON) | 300s | ~200B | 5 大指数快照 |
| `aqp:market:heat:YYYYMMDD` | bytes(JSON) | 300s | ~100B | 涨跌家数/涨停跌停/成交额 |
| `aqp:stock:profile:600519.SH` | bytes(JSON) | 6h | ~300B | 个股档案 |
| `aqp:stock:bar:600519.SH:qfq:20240101_20240801` | bytes(JSON) | 10min | ~50KB | K 线区间，key 带 adjust+range |
| `aqp:stock:limit:600519.SH:20260828` | bytes(JSON) | 6h | ~40B | 当日涨跌停价 |
| `aqp:bt:summary:{run_id}` | bytes(JSON) | 永久（可手动删） | ~5KB | 回测结果 summary |
| `aqp:model:prod:lgbm_v1` | bytes(JSON) | 1h | ~100B | 当前 prod 模型元数据（指向 model_registry 行） |
| `aqp:tradecal:all` | bytes(pickle/JSON) | 24h | ~30KB | 全部交易日 list |

### 7.3 降级方案小结

1. **Redis 全不可用**：API 返回 200，`redis="degraded"`，读走 LRU+Parquet，写仅 LRU；
2. **Parquet 无历史**：回滚到 AKShare 在线查询（限流+重试）；
3. **SQLite 锁**：所有写接口返回 `ERR_SYSTEM`，读接口通过缓存仍可用；
4. **后端宕机**：前端展示离线 Cache（Service Worker，P3 扩展）。

```ts
// 1) 实例

  if (token && config.headers) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 3) 响应拦截器：统一拆 APIResponse，code != 0 抛错
http.interceptors.response.use(
  (resp: AxiosResponse<APIResponse<any>>) => {
    const body = resp.data;
    if (!body || typeof body.code !== 'number') {
      // 可能是 /docs 或其他非 JSON
      return resp as any;
    }
    if (body.code === 0) {
      // 改写 data：直接返回 payload，方便 .then(data => ...)
      (resp as any).$payload = body.data;
      return resp as any;
    }
    const err: any = new Error(body.message || `业务错误 code=${body.code}`);
    err.code = body.code;
    err.trace_id = body.trace_id;
    err.payload = body.data;
    return Promise.reject(err);
  },
  (error: AxiosError<APIResponse<any>>) => {
    const status = error.response?.status;
    const msg =
      error.code === 'ECONNABORTED' ? '请求超时，请稍后重试'
      : status === 401 ? '未登录 / 未授权，请设置 Admin Token'
      : status === 403 ? '没有操作权限'
      : status === 500 ? '后端服务异常'
      : error.message || '网络错误';
    const e: any = new Error(msg);
    e.cause = error;
    e.status = status;
    return Promise.reject(e);
  }
);

/** 便捷：GET + 取出 payload */
export async function GET<T>(url: string, params?: any): Promise<T> {
  const resp = await http.get<any, AxiosResponse<APIResponse<T>> & { $payload: T }>(url, { params });
  return resp.$payload;
}
export async function POST<T>(url: string, data?: any): Promise<T> {
  const resp = await http.post<any, AxiosResponse<APIResponse<T>> & { $payload: T }>(url, data);
  return resp.$payload;
}

export default http;
```

## 10. 机器学习训练与推理

### 10.1 训练-推理流水线（DAG）

```
update_daily.py (每日盘后)
    → build_features.py  (增量 60 日重算特征)
        → train.py        (按周末/月底重训，valid IC > 历史 best 则切换 prod)
            → infer.py    (每个交易日输出 pred_score)
                → run_backtest() → 回测验证 → 前端展示
```

### 10.2 Label 构造与复权混用规则

| 步骤 | 使用的复权 | 原因 |
|---|---|---|
| 特征动量 `ret_w` | **qfq**（最新价基准） | 特征单调性与视觉一致，避免除权缺口造成巨大虚假 ret |
| 计算 `Label` = 未来 N 日收益率 | **hfq** 或 **qfq（当日之后滚动）** | 只要前后一致即可；推荐 qfq，因为推理当日也基于 qfq |
| 回测成交价撮合 | **none（不复权原始价）** | 必须，因为实际买卖以当日未复权价成交，复权仅用于收益指标评估 |

**防泄漏红线清单**：
1. 严禁在 `build_features` 内使用未来日期数据（`shift(-1)` 做特征）；
2. 特征选择只用 `train_mask` 内的 IC；
3. 测试集（最后 ML_HOLDOUT_DAYS 天）严禁参与任何训练、特征筛选、早停；
4. 回测必须按交易日顺序推进，不准偷看未来信号。

### 10.3 训练与评估公式

| 指标 | 公式 | 参考阈值 |
|---|---|---|
| IC（Pearson） | Pearson(pred, label_ret) | ≥ 0.03 可接受 |
| RankIC（Spearman） | Spearman(pred, label_ret) | ≥ 0.04 可接受 |
| ICIR | mean(IC_per_day) / std(IC_per_day) | ≥ 0.7 稳定 |
| 分组收益（5 组） | 每日按 pred 分 5 组，组内等权收益，累积画图 | 组 5 > 组 1，单调递增 |
| AUC（分类） | ROC AUC | ≥ 0.56 |
| 置信度合成 | `score_conf = sigmoid(a*RankIC + b*ICIR)` | 用于选股权重上限 |

### 10.4 完整训练命令


## 11. 回测引擎实现详解

### 11.1 时间轴与撮合流程

```
T-1 close 已知
    → 生成 T 日 pred_score 排名 → 目标 target_syms
T 日 open
    → SELL 非目标持仓（T-1 及之前买入），遇到封跌停跳过
    → BUY 目标仓位等权分配，遇到涨停/停牌跳过
T 日 close
    → mark_to_market 更新总资产 → T 日净值 → 换手统计
```

### 11.2 撮合细节（Broker 设计）

- **T+1**：当日买入放入 `_locked`，当日 `match()` 不可卖，`mark_to_market()` 执行时先并入可卖 `holdings`，正好匹配下一交易日可卖。
- **涨跌停判断**：用 `open` 与 `limit_up/down` 比较。`Buy: open ≥ limit_up*0.9999 → 跳过`；`Sell: open ≤ limit_down*1.0001 → 跳过`。
- **停牌**：`volume=0` 或 `is_halted=True` 跳过。
- **一手 100 股**：`_round_100()` 向下取整。
- **佣金最低 5 元**：`max(5, amount*0.0003)`。
- **印花税（卖出）**：amount × 0.0005。

### 11.3 换手衰减与筹码近似（绩效外推）

AQP 的回测默认**不含**换手衰减与滑点（为了复现稳定）。
实际研发可在 Broker 中加两项：

| 项 | 公式 | 推荐默认 |
|---|---|---|
| 买卖滑点 slippage | 成交价 = open × (1 ± bps)，买+卖− | 5 bps (0.0005) |
| 换手衰减 turnover decay | 成本 = cost + |Δweight| × decay_bps | 10 bps (0.001) |
| 筹码近似（冲击成本） | 若当日 买入额 > 股票当日成交额 × impact_pct → 加线性滑点 | impact_pct=0.02 加 5~30bps |

### 11.4 调用示例

```python
# 伪代码示意（实际集成到 scripts/backtest_run.py，P2 开发）
import pandas as pd
from app.backtest.engine import run_backtest

uni = pd.read_parquet('.../universe_daily.parquet')  # 含 limit_up/down/is_halted
sig = pd.read_parquet('.../pred_daily.parquet')

res = run_backtest(
    universe=uni, signal=sig,
    init_cash=1_000_000, top_k=10,
    rebalance_freq='daily',
    commission_rate=0.0003, stamp_duty=0.0005,
)
print(res.metrics)
# {'annual_return': ..., 'sharpe': ..., 'max_drawdown': ..., 'win_rate': ...}
```

```dockerfile
# 基础镜像：官方 python 3.11-slim（避免 alpine 的 TA-Lib / lightgbm 编译坑）

FROM python:3.11-slim AS builder

 && apt-get install -y --no-install-recommends \
        build-essential \
        wget \
        libgomp1 \
 && rm -rf /var/lib/apt/lists/*

 && ./configure --prefix=/usr \
 && make -j$(nproc) \
 && make install

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    VIRTUAL_ENV=/opt/venv \
    PATH="/opt/venv/bin:$PATH"

COPY backend/requirements.txt /tmp/requirements.txt
RUN pip install --no-cache-dir -r /tmp/requirements.txt \
        -i https://pypi.tuna.tsinghua.edu.cn/simple \
        --extra-index-url https://download.pytorch.org/whl/cpu

# ================= runtime 层 =================
FROM python:3.11-slim AS runtime

ENV TZ=Asia/Shanghai \
    PYTHONDONTWRITEBYTECODE=1 \

COPY --from=builder /usr/lib/libta_lib* /usr/lib/
```

### 13.6 `frontend/nginx.conf`（SPA + API 反代）

```nginx
# AQP 前端 Nginx 配置（容器内 /etc/nginx/conf.d/default.conf）
server {
    listen       80;
    server_name  _;

    # 基础安全头
    add_header X-Content-Type-Options    "nosniff"       always;
    add_header X-Frame-Options           "SAMEORIGIN"    always;
    add_header Referrer-Policy           "strict-origin" always;
    add_header Permissions-Policy        "camera=(), microphone=(), geolocation=()" always;

    # gzip
    gzip                on;
    gzip_min_length     1024;
    gzip_comp_level     5;
    gzip_vary           on;
    gzip_types
        text/plain text/css text/xml
        application/json application/javascript application/xml
        application/xml+rss image/svg+xml;

    # 静态资源长缓存（Vite 带 hash）
    location /assets/ {
        alias   /usr/share/nginx/html/assets/;
        expires 30d;
        access_log off;
        add_header Cache-Control "public, max-age=2592000, immutable";
    }

    # API 反代到 aqp-api 容器（docker compose 内 DNS 解析）
    location /api/ {
        proxy_pass         http://aqp-api:8000/api/;
        proxy_http_version 1.1;

        # 反代头
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 读超时（批量回测接口可能慢）
        proxy_read_timeout                 180s;
        proxy_connect_timeout              5s;
        proxy_send_timeout                 60s;

        # 缓冲：行情响应较小，开缓冲减少 IO
        proxy_buffering on;
        proxy_buffer_size 4k;
        proxy_buffers 8 16k;
    }

    # 健康检查
    location = /healthz {
        access_log off;
        return 200 "ok\n";
        add_header Content-Type text/plain;
    }

    # SPA 路由兜底：其他路径一律回 index.html
    location / {
        root   /usr/share/nginx/html;
        index  index.html;
        try_files $uri $uri/ /index.html;
    }
}
```

## 15. 常见问题 FAQ（25 条）

> 格式：每条 = **症状** / **原因** / **解决**。用户可直接 Ctrl+F 搜关键词。

### FAQ-1 PowerShell 激活 venv：「因为在此系统上禁止运行脚本」

- **症状**：`.\.venv\Scripts\Activate.ps1` 报 `UnauthorizedAccess / 执行策略`。
- **原因**：Windows 默认 PowerShell 执行策略为 `Restricted`，禁止运行 `.ps1`。
- **解决**：
  ```powershell
  # 仅当前用户级开启 RemoteSigned（安全做法，不影响系统）
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  # 选 [Y] 确认。重开 PowerShell，再激活 .venv 即可
  ```
  临时替代：`cmd.exe` 内用 `.venv\Scripts\activate.bat`（无策略限制）。

### FAQ-2 `pip install TA-Lib` 失败（Windows 最常见）

- **症状**：报 `error: Microsoft Visual C++ 14.0 or greater is required` 或 `Failed building wheel for TA-Lib`。
- **原因**：TA-Lib 需要先装 **C 语言原生库**；pip 直接装不会自动装 C 库。
- **解决**（推荐 3 条路，选其一）：
  1. **预编译轮子**：到 <https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib> 下载对应版本，例如 `TA_Lib-0.4.28-cp311-cp311-win_amd64.whl`，然后 `pip install <该文件>`。
  2. **conda 装**：如果你装了 Anaconda/Miniconda → `conda install -c conda-forge ta-lib`。
  3. **手动编译**：先装 Build Tools for Visual Studio 2022（勾选 "Desktop development with C++"），再解压 `ta-lib-0.4.0-src.tar.gz` 到 `C:\ta-lib`，然后 `pip install ta-lib`。
- Mac M1/M2 用户：`brew install ta-lib` 再 `pip install ta-lib`。

### FAQ-3 Mac M1/M2 安装 `lightgbm` 编译失败

- **症状**：`clang: error: the clang compiler does not support '-march=native'` 或 `library not found for -lomp`。
- **原因**：Apple Silicon 需要用 `libomp`，且默认 march=native 不可用。
- **解决**：
  ```bash
  brew install libomp
  export LDFLAGS="-L/opt/homebrew/opt/libomp/lib"
  export CPPFLAGS="-I/opt/homebrew/opt/libomp/include"
  pip install lightgbm --no-binary lightgbm
  ```
  仍失败时直接 `conda install -c conda-forge lightgbm`。

### FAQ-4 AKShare 拉日线报 429 或 `ReadTimeout`

- **症状**：`ak.stock_zh_a_hist()` 抛 `timeout` 或返回空 DataFrame。
- **原因**：东方财富/Sina 接口对高频请求临时封禁；同一 IP 连续快速访问触发。
- **解决**：本模板已在 `AkshareAdapter` 里内置 **sleep 0.35~0.7s 抖动 + tenacity 指数回退（1s → 2s → 4s，共 3 次）**。
  - 仍失败时：降低并发（单线程拉）、临时改 `akshare_adapter.py` 的 `_sleep` 为 `1.0~1.5s`、换家庭网络、或在非交易时段 18:00+ 后跑（东财夜间限速松）。

### FAQ-5 `npm install` 报 `ERR! network / ETIMEDOUT / ECONNRESET`

### FAQ-6 `pip install` 慢（默认官方源）

### FAQ-7 Redis 连接被拒：`Error 111 connecting to 127.0.0.1:6379`

- **症状**：接口返回 `code=50000` 或日志 `ConnectionRefusedError`。
- **原因**：Redis 没启动或 `REDIS_ENABLED=true` 但没装 Redis。
- **解决**（三选一）：
  1. **本机**：Windows 用 Memurai（Redis 兼容社区版）或 WSL 里 `sudo apt install redis-server && redis-server --daemonize yes`；Mac `brew services start redis`。
  2. **开发模式关 Redis**：`.env` 里 `REDIS_ENABLED=false`（AQP 自动降级到内存 LRU，纯开发够用）。
  3. **Docker 模式**：`docker run --name aqp-redis -d -p 6379:6379 redis:7.2-alpine`。

### FAQ-8 Python venv 创建失败：`Error: [Errno 28] No space left on device`

- **症状**：`python -m venv .venv` 抛设备无空间。
- **原因**：磁盘满；或 Windows 系统盘用户配额；或 Mac 开启了 APFS 快照。
- **解决**：
  - `df -h` / 此电脑 → 清掉 `~/Library/Caches`、`C:\Users\xxx\AppData\Local\pip\cache`、`node_modules`；
  - pip 清缓存：`pip cache purge`；npm 清：`npm cache clean --force`；
  - 挪仓库到数据盘，如 `D:\Python_Project`。

### FAQ-9 SQLite `database is locked / OperationalError`

- **症状**：写入或跑训练时突然抛 `sqlite3.OperationalError: database is locked`。
- **原因**：SQLite 单写多读，两进程同时 `COMMIT` 或 uvicorn `--workers 4` 多进程争写。
- **解决**：
  1. 开发：`uvicorn --workers 1`（本模板默认），避免多 worker；
  2. 增加超时：`connect_args={"timeout": 30}`（已在 `session.py` 里加了）；
  3. WAL 模式：`PRAGMA journal_mode=WAL;` + `PRAGMA synchronous=NORMAL;` + `PRAGMA busy_timeout=30000;`（已在 `init_db.py` 和 `session.py` connect_args 里执行，DB 级持久化生效）；
  4. 写入密集场景：换 PostgreSQL（P3 任务）。

### FAQ-10 后端端口 8000 被占用：`Address already in use`

- **症状**：`uvicorn` 启动报 `[Errno 10048] error while attempting to bind on address`。

  - Mac/Linux：

    ```bash
    kill -9 <PID>
    ```

### FAQ-11 前端端口 5173 被占用（Vite）

- **症状**：`Port 5173 is in use, trying another port` 或 `npm run dev` 弹到 5174，但你的 proxy 写死 5173。
- **原因**：其他 Vite 项目仍在跑。
- **解决**：先关别的项目；或强制指定端口 `npm run dev -- --port 5173 --strictPort`。

### FAQ-12 CORS 报错：`blocked by CORS policy: No 'Access-Control-Allow-Origin'`

- **症状**：DevTools Console 红色报 CORS，接口 200 但前端拿不到数据。
- **原因**：后端 `CORS_ORIGINS` 未包含 `http://127.0.0.1:5173` 或实际域名。
- **解决**：`.env` 里加逗号分隔的完整 Origin：

### FAQ-13 接口 422 Unprocessable Entity（Pydantic）

- **症状**：`curl /api/v1/market/kline/600519` 返回 `422 {"detail":[{"loc":["query","adjust"]...}]}`。
- **原因**：`adjust` 枚举只允许 `qfq/hfq/none`，缺省或拼写错。
- **解决**：补 `?adjust=qfq`。其他 422 看 `detail[].loc` 定位参数名，再看章节 9 文档。

### FAQ-14 前后复权不一致，回测收益率完全失真

- **症状**：训练 holdout IC 正常，但回测 `annual_return=-95%` 这种极端值。
- **原因**：特征用 `daily_qfq` 预测，回测成交价却拿 `daily_hfq` 甚至 `daily_none`；或某段 `adj_factor` 缺失。
- **解决**（硬规则，章节 10 已强调）：
  - 特征 / Label 训练**统一**用 `qfq` 或 `hfq`（模板默认 qfq）。
  - 回测成交价必须用 `daily_none`（不复权原始价），涨跌停用 `daily_none` 算。
  - 先跑 `python -m app.data.validate`，确保 `adjust_factor.parquet` 无 NaN。

### FAQ-15 Parquet 写入后读出来是空 DataFrame

- **症状**：`pd.read_parquet('daily_qfq.parquet').shape == (0,0)`。
- **原因**：模板写入是原子两步（写 `tmp` → `os.replace`），如果写 `tmp` 时异常中断会残留 0 字节 tmp，但不会破坏主文件；**主文件为空**说明第一次写 `df.to_parquet(tmp)` 本身 df 就是空。
- **解决**：
  1. 检查 `ak.stock_zh_a_hist()` 返回的 df：拉取日期范围过小（如全是周末）或接口挂了 → 换个日期范围；
  2. 用 `head` 命令看 5 行：`python -c "import pandas as pd; print(pd.read_parquet('xxx.parquet').head())"`；
  3. 清掉坏数据重跑：`rm data/parquet/daily_*.parquet && python scripts/bootstrap.py --stage daily ...`。

### FAQ-16 时区问题：`trade_date` 被当作 UTC，训练切分比预期少一天

- **症状**：`2024-02-29 23:59 UTC` 被存成 `2024-03-01 08:00 CST`，日期对不上。
- **原因**：pandas `to_datetime` 默认 naive，但存储到 Parquet 后读入被 Arrow 当成 UTC；或 `TZ` 环境变量未设。
- **解决**：
  - `export TZ=Asia/Shanghai`（Linux / Docker .env 里已设 `TZ=Asia/Shanghai`）；
  - Windows 全局：`.venv\Scripts\python -c "import os; os.environ['TZ']='Asia/Shanghai'; import time; time.tzset()"`（Windows 用 `tzlocal`，模板在 `config.py` 里统一做了 naive→Asia/Shanghai）。

### FAQ-17 路径含中文导致报错（Windows 用户名中文）

- **症状**：`UnicodeEncodeError: 'gbk' codec can't encode character...` 或模块导入失败，路径里有 `C:\Users\张三\.venv\...`。
- **原因**：Windows 默认 `PYTHONIOENCODING` 是 GBK，子进程继承后写日志乱码。
- **解决**：
  - PowerShell 全局变量：
    ```powershell
    $env:PYTHONIOENCODING="utf-8"
    $env:PYTHONUTF8="1"
    ```
    永久生效：`[Environment]::SetEnvironmentVariable('PYTHONUTF8','1','User')` → 重开 PS。
  - 仓库放非中文路径（示例 `D:\Python_Project\aqp`）避免用户名路径陷阱。

### FAQ-18 Windows 防火墙弹窗挡住 uvicorn 外网访问

- **症状**：`uvicorn --host 0.0.0.0` 本机 `127.0.0.1:8000` 可通，但同局域网手机不行。
- **原因**：首次启动时 Windows Defender 弹了"是否允许访问"，点了取消/专用网络没勾。
- **解决**：设置 → Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 更改设置 → 勾选 Python（uvicorn 那个进程）专用/公用两个框。

### FAQ-19 WSL2 上跑 docker，容器时间比主机慢 8 小时

- **症状**：容器内 `date` 比宿主机 `date -u` 慢 8 小时，导致交易日历判断偏差。
- **原因**：WSL2 休眠唤醒后 `hwclock` 漂移，Docker Desktop 默认 UTC。
- **解决**（WSL2 + Docker Desktop）：
  1. 管理员 PowerShell：
     ```powershell
     wsl --shutdown
     ```
  2. 重启 Docker Desktop；
  3. Dockerfile / compose 里显式设 `TZ=Asia/Shanghai`（模板已加）。

### FAQ-20 训练出现 "IC 异常高"（> 0.3），疑似标签泄漏

- **症状**：训练 IC 0.38，holdout IC 0.02，典型过拟合 + 泄漏。
- **原因**：
  1. 特征里用了 `df['close'].shift(-1)`、`label = close_fut_5 / close - 1` 然后特征构造时 shift 负方向；
  2. IC 筛选用到了 holdout 段；
  3. 标准化 `StandardScaler().fit_transform(df)` 对整个 df 一次性做了（包含 holdout）。
- **解决**（模板已做了前两条防泄漏）：
  1. 特征构造禁止 shift(-N)，仅允许 shift(+N)；
  2. IC 筛选只用 `train_mask`，早停只用 `val_mask`，holdout 完全不出镜；
  3. 标准化按 `train_mask` 计算 mean/std 再 transform 全数据；
  4. 每次改完特征立刻 `pytest tests/` + 跑一次章节 12 的 S4.2/S4.3 对比 IC 合理性。

### FAQ-21 新股首日涨跌停 ±44%，用常规 10% 过滤导致回测误开仓

- **症状**：回测日志里有上市首日股票，Broker 判定 `limit_up=prev_close*1.1`，但实际开盘 1.44×，结果撮合开仓。
- **原因**：AQP 简化实现 `limit_up_price(prev_close, 0.1)`；科创板/创业板是 ±20%、新股首日 ±44%、ST ±5%。
- **解决**（P1 任务项已列出）：
  1. 在 `instruments` 表加 `board`（主板/创业板/科创板/ST/北交所）；
  2. `limit_up_price()` 增加 `list_days` 入参；首日 `limit=0.44`，2~5 日按板块；
  3. 模板已在 `domain/limit.py` 里放了 `LIMIT_PCT_BY_BOARD` 字典占位，按实际字典填充即可。

### FAQ-22 Gunicorn 多 worker 下内存爆掉（训练并发）

- **症状**：`--workers 4` 起后端，跑选股 API 时 4 个 worker 各复制一份模型，内存飙升。
- **原因**：Python GIL + forking，LightGBM Booster 不会 COW 共享；还会叠加 pandas 临时 DataFrame。
- **解决**：
  1. API 模式用 `--workers 1`，CPU 密集任务（训练/回测）单独跑离线脚本（模板就是这样设计的）；
  2. 大流量 P3：把训练/回测抽成独立 worker 队列（Celery/RQ），API 只提交任务。

### FAQ-23 升级依赖后 `pydantic` 报错（v1→v2）

- **症状**：`from pydantic import BaseSettings` → `ImportError: cannot import name 'BaseSettings'`。
- **原因**：AQP 模板依赖 `pydantic>=2.0`，`BaseSettings` 移到了 `pydantic-settings` 包。
- **解决**：模板 `requirements.txt` 里固定了 `pydantic-settings>=2.0`，如果你手改了版本：
  ```bash
  pip install -U pydantic pydantic-settings pydantic[email]
  ```
  同时确保 SQLAlchemy 用 `sqlalchemy>=2.0.20` + `greenlet>=3.0`（异步 session 需要）。

### FAQ-24 交易日历始终返回空集合，`is_trade_day()` 永远 False

- **症状**：API 请求中调用 `is_trade_day(d)` 始终返回 False，但 SQLite 中 `trade_calendar` 表有数据。
- **原因**：旧版 `ensure_loaded()` 在同步函数中调用 `asyncio.run()`，但 FastAPI 请求运行在事件循环中，`asyncio.get_running_loop()` 捕获到正在运行的 loop 后触发 fallback，返回空集合 `_TRADE_DAYS = set()`。
- **解决**（已在模板修正）：
  1. 在 `main.py` 的 `lifespan` 启动钩子中显式调用 `await load_trade_calendar_async()` 预加载；
  2. `ensure_loaded()` 的 fallback 改为同步 `sqlite3` 直连查询（不再碰 `asyncio`）；
  3. 脚本场景直接调 `load_from_db_sync()` 或 `load_from_list()`。

### FAQ-25 Parquet 小文件过多导致磁盘 IO 性能骤降

- **症状**：全量拉取 5000 只 × 10 年数据后，磁盘出现数百万个微型 `.parquet` 文件，读取/扫描极慢，Windows 资源管理器卡死。
- **原因**：旧版 `path_for()` 按 `part-YYYYMMDD.snappy.parquet` 按日分区，5000 × 240天 × 10年 = 1200 万个文件。
- **解决**（已在模板修正）：
  1. 改为按年分区 `year=YYYY.snappy.parquet`，5000 × 10 = 5 万个文件；
  2. 增量更新用 `write_partition()` 自动 concat + 去重 + 原子重写；
  3. 首次拉取用 `write_year_batch()` 整年批量写入；
  4. 读取单年用 `read_symbol_year()`，跨年用 `read_symbol_dataset()` 自动拼接。
