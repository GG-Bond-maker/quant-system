## 前置检查（必须全部满足再启动）

1. **磁盘余量 ≥ 8G**（预计 +3~4G；当前 9.8G 满足，但需在启动前复测）：
   ```bash
   df -h /d   # 或 wizdir 扫描确认 D 盘外部大文件已清理
   ```
2. **水位预警已生效**（设置页磁盘 ≥90% 即 warning）——扩容期间若触发 90% 预警，冻结抓取。
3. **Redis 常驻**（aqp-redis 运行中，扩容后查询走快照/缓存才有验收性能）。
4. 时间预算：3 线程 ~5s/只 × 4400 只 ≈ 6~8 小时/口径 × 3 口径（新浪限速为延迟型；可分多晚跑）。

## 执行步骤

```bash
cd backend
# 1. 全量清单预演（不抓取，先看要拉多少、跳过多少）
.venv/Scripts/python.exe ../scripts/fetch_universe_batch.py --help

# 2. 启动批量抓取（断点续传：中断后重跑同一命令自动跳过已完成标的）
.venv/Scripts/python.exe ../scripts/fetch_universe_batch.py --limit 4400 --start 2022-01-01

# 3. 全部完成后重建衍生数据（universe/features/cs mirror，manifest 加速生效）
.venv/Scripts/python.exe scripts/build_features.py
.venv/Scripts/python.exe -m app.data.pipeline   # 盘后流水线全量
```
