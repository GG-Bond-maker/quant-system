
【项目基本信息】
- 项目名称：A股智能量化预测与分析平台

- 硬件环境：Intel Core Ultra 5 125H + 32GB RAM（优先采用CPU友好方案）
- 核心定位：以机器学习预测为核心，融合传统量化选股、技术分析、资金面、基本面与AI辅助分析的A股智能研究平台。

【详细功能需求】
1. 市场概览模块
- 主要指数实时与历史走势
- 市场涨跌分布、成交额统计
- 北向资金与主力资金流向
- 热门板块/概念排行与轮动
- 异动监控（涨停、放量、快速波动）
- 基于机器学习模型的每日预测推荐榜
- 市场情绪与简要AI解读

2. 个股详情模块（核心）
- 专业K线图表（日/周/月，支持复权、缩放、十字光标）
- 叠加均线、成交量
- 技术指标副图（MACD、KDJ、RSI、BOLL等）
- K线形态自动识别与标注
- 筹码分布图
- 最新行情数据卡片
- 机器学习预测面板（预期收益率/涨跌概率、置信度、历史IC与准确率、因子贡献解释）
- 资金面（主力、北向、龙虎榜、大宗交易）
- 基本面数据
- 相关新闻与公告
- 可选AI智能解读
- 同行业对比

3. 量化选股中心
- 多维度条件选股（技术、形态、基本面、资金等）
- 内置经典策略选股（放量上涨、均线多头、回踩年线、突破平台等）
- 基于LightGBM/Qlib模型的智能选股与排序
- 选股结果支持回测、加入自选、导出

4. 回测与绩效中心
- 策略回测与模型信号回测
- 严格遵循A股规则（T+1、涨跌停、停牌）
- 完整绩效指标（年化收益、夏普、最大回撤、胜率、盈亏比等）
- 净值曲线、回撤曲线、与沪深300基准对比
- 回测报告生成

5. 自选与监控
- 自选股分组管理
- 价格、指标、预测信号预警

6. 系统管理
- 数据更新监控
- 模型版本管理
- 缓存与日志管理

【技术栈】
- 后端：FastAPI + Uvicorn
- 前端：React + Vite + TypeScript + Tailwind CSS + shadcn-ui/Ant Design
- K线图表：TradingView Lightweight Charts
- 其他图表：ECharts
- 数据获取：AKShare（主）+ BaoStock
- 数据处理：Polars + Pandas
- 数据存储：Parquet（海量历史数据）+ SQLite/PostgreSQL
- 缓存：Redis + 进程内缓存
- 量化框架：Microsoft Qlib
- 技术指标：TA-Lib / pandas-ta
- 机器学习：LightGBM（主力）+ XGBoost
- 可选AI：DeepSeek / OpenAI兼容接口
- 部署：支持Docker Compose
