## 六类归因分解（计划规定口径）

### 1. 除权修正（T1）——最终差异的**全部正贡献来源**

raw→hfq 结算口径切换：现金分红除息不再凭空记账亏损、送转除权不再凭空
腰斩市值。窗口内实测 15 个除权事件落在持仓路径上，修正量级 **+1.4852pp/年**
（T1 A/B：annual -5.6763% → -4.1911%）。整手换算经 factor 域换算修复后，
lot 拒绝与 raw 域逐数一致。详见 `task1-AB.md`。

### 2. 退市减记（T6）——本窗口**零贡献**

`enrich_delist.py` dry-run 实测：退市名单 361 条与本地 1133 只宇宙
**交集 0 条**（宇宙抽样自当前在市股票——幸存者偏差本身），强平机制从未触发，
`task6-after.json` 与 before 逐数相同。修复价值在**结构预防**：今后宇宙内
任何股票退市，持仓将按 haircut 强平而非永久冻结估值。

### 3. 冲击成本（T5）——无摩擦主路径**零贡献**

本对比与基线同为无摩擦参数（friction_costs 全 0）。T5 的价值是接通流动性
口径并如实披露：开摩擦路径实测 impact=2,057.66 元（首次真实非零），全套
摩擦把年化从 -5.2% 压到 -26.1%（daily×122 倍年化换手的代价）——该量级
披露见 `task5-AB.md`，不进入本主表差异。

### 4. 闸门收紧（T7）——主回测路径**零贡献**

T7 统一的是**策略引擎**口径（ma_cross 专用无闸门引擎 → broker 框架），
27.6pp/年的虚高修正发生在策略页面场景（`task7-engine-compare.json`）。
Top-K 主回测自 T1 起即带全套闸门（停牌/涨跌停/T+1），不在 T7 影响面内。

### 5. 信号版本隔离（T2）——最终差异的**全部负贡献来源**（方向不代表有害）

混版信号（`*_pipe`×4 天 + `bulk1133_demean`×1 天）被剔除，整个窗口只用
单一模型口径（`lgbm_v1_20260830_095940_repaired`，252/257 天覆盖）：
annual -0.9696pp、filled 3037→3013、lot 拒绝 338→341。被剔除日的信号来自
不同模型配方，其"贡献"无法与主版本归因区分——修复目标是**可解释性**
（结果可复现、口径单一），而非方向性改善。详见 `task2-AB.md`。

### 6. qfq 数据重建（T3）——**单列**：改的是数据本身，不进主表

T3 修复对象是 `daily_bar_qfq` 数据集（qfq = hfq/F_last 全量本地推导 +
采集默认口径去 qfq），主回测结算用 hfq（`universe_daily_bt`），**不消费
qfq → 对主表零直接贡献**。其影响在数据层与单股策略回测：真实漂移仅
1/1130 只（300750.SZ，1.9%），策略影响 ≤0.12pp/年（专项证据
`task3-AB.md` + `task3-ma-cross.json`）。结构性收益：rebuild_qfq 进入每晚
流水线后 qfq 恒等式数学上恒成立，漂移从此结构性不可能。

**闭合校验**：+1.4852（T1）− 0.9696（T2）= **+0.5156pp = 主表年化总差** ✓
